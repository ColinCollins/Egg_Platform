# DLevel_059 风险评估

## 1. 需求与基线

D059 复制 D058，并沿用猫夹角色释放、蜂群命中失败和坚持倒计时成功。静态检查表明玩法链完整；当前明确问题与 D058 相同：Actor 继承共享零摩擦材质，落地后可能沿地面持续滑走。

## 2. 修复与边界

- 在 `DLevel_059.prefab` 的嵌套 Actor 根 Rigidbody2D 上，局部覆盖已有 `DrawStrokeStable.physicsMaterial2D`。
- 该材质摩擦为 `0.8`、弹性为 `0`，摩擦合并为 Maximum；不增加阻尼、不冻结 X、不持续改写速度。
- 保留本关 `strokeMass=100`、蜂群冲量、场景障碍、蜂巢位置和地面布局；不改共享 Actor、DLevel2/D053 代码、配置、UI、存档或 SDK。

## 3. 主要风险

1. **复用链风险（高）**：059 依赖 `DLevel58ActorReleaseCtrl : DLevel2Ctrl`。未来改动 DLevel2 的 Intro、夹子动画、脱父级或 Retry 时，必须同时回归 002、020、047、058 和 059。
2. **结算竞争风险（高）**：7 秒成功与蜂群首次命中后的 1.5 秒失败演出共享 Draw 结算占用；当前字段齐全，但临界时刻的胜负互斥仍需 PlayMode 验证。
3. **高冲量与摩擦风险（中）**：059 蜜蜂冲量高于 058。Maximum 高摩擦用于抑制自然滑走，但会改变角色被画线、障碍或蜂群挤压后的停止距离；不应再用锁轴或持续归零补丁。
4. **布局差异风险（中）**：两枚静态圆障碍、较低蜂巢和删除长地面会改变蜂群通道与 FallArea 触发机会；它们像有意设计，本轮保留。
5. **复制残留风险（低）**：已删除原球仍留有无效 Override。当前没有本地悬空 fileID 或 Missing Script，清理收益不足以覆盖 Prefab Override 误伤风险。

## 4. 验证与回滚

- 已静态验证运行时配置唯一性、全部脚本 GUID、Prefab anchor/本地引用、猫夹字段、蜂群/特效/倒计时字段及防滑材质唯一性。
- 未启动第二个 Unity 实例，也未执行 PlayMode；实际停止距离、开夹、蜂群碰撞、成功/失败临界、Retry 和移动端为 `uncertain`。
- 回滚本轮修复时只移除 D059 Actor Rigidbody2D 的 `m_Material` Override；共享资源及 D058 不受影响。
