# Level151 风险评估

更新时间：2026-09-17

## 基线、范围与复用边界

用户提供的 151 是 128 的复制件，仅根名称不同。用户最终要求只固定密码 `1358`，密码线索位于其它关卡，剩余玩法维持原样。本轮影响本关 Prefab、新增 `Level151Ctrl`、`Level151PasswordPopup`、私有密码 Prefab、meta 与本关文档。

复用既有 PasswordPopup 基类、原控件对象、Level6GamePanelFeature、GameSettingPopup、四个 DragableItem、门事件 ID 1、PlayCtrl 重建和成功流程。基类生成字段为 private，本关另行显式绑定同一批控件，不修改其访问级别。不修改 128 或共享脚本、配置、存档、打点、GF 与 Packages。

编译、纯密码校验与静态一致性不代表 PlayMode、移动端或存档打点已经验证。上述待补验场景仍为 `uncertain`。输出位于 `Temp/Level151/compile.log`、`password-checks.log` 和 `static-results.json`。

回滚只恢复 151 Prefab 的旧控制器 GUID 并移除本关新增脚本、资源及 meta，保留用户原场景；配置与旧关卡均无需回滚。备份和验证输出放在 `Temp/Level151/`。当前没有待确认的密码规则。
