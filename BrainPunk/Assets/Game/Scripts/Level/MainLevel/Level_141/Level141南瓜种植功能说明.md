# Level 141 南瓜种植功能说明

## 当前有效结论与依据

本关实现“顶盒出种 → 有空位直接播种／满田落地等拾取 → 芽、草、花各五秒后成熟 → Actor 收集交付或手动摔碎繁殖 → Farmer 留钥匙 → 玩家拾钥匙开门”。依据是用户逐轮确认的需求：盒子有空位自动播种，满田盒子种子和碎瓜种子均须拾取后播种；只有 Actor 接触成熟南瓜才收集、计数，百分比按指定对照表封顶 99%。Farmer 未收满时飞给 Farmer，收满后飞向 HUD 图标；点击只用于抓起拖摔，不自动交付，也不计数。

2026-09-20 更新：本轮按用户最新反馈调整等待错误音效、收集抛物线、角色与植物层级、碎瓜种子和自由拖摔。生产编译通过；隔离 Unity 使用实际脚本、Prefab、Actor 和素材通过针对性运行检查。完整正式业务结算、主工程 HUD、本地化刷新、真机触控与最终混音仍为 `uncertain`；详细证据见末尾本轮记录。

## 开局与种子盒

- 十个手工南瓜组保留编辑态造型和坐标；每个新关卡实例在 `Awake` 就隐藏其南瓜／叶子，不等到 `Start`，避免实例化首帧露出成熟样板。后续初始化形成空田，不移动 TD、背景、玩家或门。
- 盒子开局立即可领。每次有效顶盒产一颗种子；顶盒当刻按 X 从左到右预占首个空位，有位就直接跳入土中，无位则落到原 `盒子 X+1.05` 的地面等待拾取。满田分支一经确定，飞行期间或落地后新出现空位都不能绕过拾取。
- 盒子种子从盒面中心直接沿一条连续的小抛物线飞到预定种植位或满田落点，不再分成“直线上升 0.35 秒、然后重新起跳”两段。总时长保留 `0.35 + seedFlightSeconds`，当前 0.95 秒；根据起终点高度反算弧线系数，让实际最高点只比盒顶的最高上弹位置加种子半高再高 0.15 世界单位，避免落点低于盒子时固定小系数导致种子直接向下飞。落点高于该高度时，最高点至少高于落点 0.15。
- 冒出起始仍在盒子 SortingGroup 后一层，当前为 `SceneLayer/49`；种子完整越过盒顶最高上弹位置或横向离开盒面后才切到 `SceneLayer/220`，之后不再切回盒后。只调整盒子出种轨迹；碎瓜种子的随机落地抛物线见下文；拾取种子的入土时长与弧线保留。
- 出种期间通过 `boxSeedInFlight` 锁住领取，不显示冷却条。种子入土或满田落地时才开始本次冷却：首轮10秒，之后每次加5秒（15、20、25……），最高60秒，达到后一直60秒，随后条渐显、从满减到空，结束渐隐；不创建分秒文字、不显示 `1:00`，也不自动产下一颗。
- Farmer 离开、玩家拿到钥匙或门已解锁，都不会关闭种子盒；关卡仍在进行且冷却结束时可以继续顶盒领种，真正进门通关、失败或暂停后才受对应游戏状态限制。
- 每次有效顶盒仍播放一次 `getCoin`。出种飞行或当次冷却中再次触发播放 `passwordError`，不多发种子、不重置时间；冷却中仍只晃进度条。有效领取时盒面轻微上弹，碰撞体不随图像移动。
- 保留原 `Raycast2DExecutor` 的 `distance=0.5`、`direction=(0,-1)`、`radius=0.25`、Actor 层检测以及接触去重。
- 移除原箱子的音效监听器／延迟／两项三次切换事件；顶箱 `getCoin` 统一由本关入口触发，避免重复。旧金币实例和旧 MMF 资产保留为停用内容，不恢复其金币演出。

## 拾种与播种

1. 盒子有空位时走直接入土分支，不要求拾取；出盒时满田的种子和摔碎产生的十颗种子必须先落地、再由 Actor 拾取。以当前 `level.Actor` 的实体 Collider 与种子可见范围接近判定，不是点击屏幕捡取。首次登记 `picked` 时通过项目 AudioManager 播放一次 `getCoin`；盒子直接入土不伪造拾取、不额外播放拾取音，满种等待、后续补种和入土也不重复播放。
2. 需要拾取的种子在被拾取前始终留在地面，不会因为空田出现而自动入土。
3. 两条播种路线共用 `ReserveLeftmostSite`，按十个南瓜本体中心的世界 X 从左到右预占空位；盒子在冒出前预占，拾取种子在入土飞行前预占，避免多颗种子占同一位置。
4. 全满时已拾取的剩余种子也留在落地位置，以略淡的颜色表示等待；空位释放后自动补种，不要求重复拾取。未拾取种子仍不参与。
5. 土中落点沿成熟南瓜本体底部对齐；生长进度条水平对齐成熟南瓜本体中心，条的中心放在成熟南瓜顶部上方 0.35 世界单位，避免覆盖幼苗和南瓜。初始化与每轮播种共用该位置；不使用 SortingGroup 根枢轴或叶子中心，盒子倒计时条位置不变。

种子来源只影响是否需要拾取和是否播放冒出演出，入土后统一生长。没有种子自动过期、库存上限或跨局保存；成熟南瓜仍需 Actor 接触才收集，不因自动播种而自动收走。

## 收集、交付和摔碎

- Actor 接触成熟南瓜是唯一自动收集入口，登记 `collected` 后增加 HUD 收集数；点击／松手不调用收集。指针优先，正在持有或已进入 `throwing` 的南瓜不允许 Actor 自动收走。已实收＋已预约达到十但最后一份尚未送达时，额外南瓜暂留原位，实际收满后才切到 HUD 收集。
- `CountCollection` 只在 Actor 收集时播放一次 `getCoin` 并刷新数量／百分比。手动抓起、扔下和摔碎都不增加 HUD 数量／百分比，不播放拾取音、不交付 Farmer；摔碎仍播放 `crashBroke` 并生成十颗种子。
- 两条南瓜收集路线使用 `collectSpeed=15` 推导时长 `max(0.35, 起终点直线距离/15)`。飞给Farmer保持原大小，实到后登记交付；Farmer收满后飞向HUD图标，随时间进度缩到图标实际宽高后隐藏。
- 两条路线都只将飞行南瓜本体临时移出田间 SortingGroup，挂到本关运行根并设为 `SceneLayer/320`，高于需求气泡 300 和 HUD 310。换父级时保留世界位置、旋转和尺寸，随后在新父级坐标系记录飞行起始缩放；收集临时提层不连带提升叶子或共享UI；本轮种植组210及收集路径调整见相邻条目。到达后先隐藏，再恢复原父级、同级索引、局部姿态和 Renderer 排序；占位仍按原叶子渐隐门槛释放。关卡禁用／销毁时按种植位登记恢复，不能依赖已被重开流程清空的飞行列表；暂停或重开等待期间仍冻结末帧，不提前闪回田中。
- 参照共享 `ItemJumpToListener` 的钥匙飞门公式：`Lerp(start,end,t) + up*4*2.5*t*(1-t)`，t由本关有效时间线性推进；移除32段路径追赶，位置和缩放直接按时间采样。HUD目标仍在镜头跟随后的LateUpdate更新；Farmer交付仍只在抵达时完成。暂停、重开沿用本关统一时钟，不新建独立Tween。
- HUD 目标从 TMP 的内联 Sprite 字符四角计算世界中心与尺寸，跟随计数排版、语言、字体和相机移动更新；收集动画在 LateUpdate 相机跟随后推进，避免用上一帧镜头位置。若图标尚未生成，保留南瓜和计数，不飞向错误位置；提示一次警告，可继续尝试收集。
- 拖动只移动南瓜本体，叶子留原处；允许左右和斜向移动，向下位移仍限制在原高度以上。位移长度达到0.65世界单位登记投掷状态，松手在当前X竖直落下；纯横向拖开也可砸，不再要求原地升高。
- 轻点或未达到有效距离的拖动回原位，不收集、不计数、不交付；移除原 18px 轻点收集判定。若取消时 Actor 正与该南瓜重叠，需离开后再次接触才能自动收集，避免松手被误表现为点击交付。鼠标和触摸使用独立指针归属，屏幕 UI 命中不开始本关操作。
- 已有效拖起后取消指针／暂停，转入待下落状态，暂停结束再继续；投掷全过程不改收集计数。
- 南瓜下落以本关重力和地面射线判断首次着地；触地后用 0.24 秒短距离裂开与轻微回弹，不加烟雾、旋转或远距离爆炸飞散。整瓜与三瓣仅在前四分之一时长（当前 0.06 秒）交叉淡变，之后三瓣保持不透明完成回弹。沿用已接受的最终状态：两侧相对落点各偏移整瓜可见宽度的 0.35 倍，小瓣位于落点中心并绘制在前；三片素材、0.9 缩放和最终贴地位置均不变。
- 触地进入 `Shatter` 时播放一次 `crashBroke`，沿用 007／102 箱子碎裂、127 砖块碎裂的现有音效；不在三瓣循环、回弹或消失时重复播放。075 门被压碎使用的是另一音效 `blockByDoor`，本关南瓜不采用该门音效。拾取的 `getCoin` 和共享钥匙的音效不变。
- 最终落点仍按 Sprite 网格最低点与脚下地面确定，横向起点取最终偏移的 55%，使用 OutQuad 短距离分离；同时增加最高 0.1 世界单位的小回弹，三片高度依次为该值的 100%／85%／70%，前方小瓣在过渡的 85% 时先落定。过渡结束精确回到原最终位置，再释放种植位并开始原有 0.6 秒停留／0.6 秒渐隐；未消失的叶子仍遵守释放门槛。全过程受本关暂停／清理控制，时长和回弹高度可在总控调整；十颗种子仍在触地当帧生成。
- 摔碎不增加 Farmer 实收数，也不增加收集数。
- 三片碎瓜保持SceneLayer/215～217、原位置及0.9缩放；所有种子最终等比0.9，离盒后及碎瓜均排序220。碎瓜数量十颗，间距基准0.6（原X±2.7）再各自随机±0.18落点；独立高抛/旋转后按地面贴底，仍须玩家拾取。盒子满田落点及碎片位置未改。
- 拖动、飞行、下落期间仍占原位；交付动画结束或摔碎后，如果成熟叶子的 2 秒渐隐尚未结束，则等待它完成再释放种植位；叶子已经消失则直接释放。摘取不重启叶子渐隐、不把透明度恢复为可见；未摘取的南瓜不会因为叶子消失就释放种植位。

## 两套计数、Farmer 与门锁

- 相机下 `Level141CollectedPumpkins` 使用世界 `TextMeshPro + Localize`。默认字体、材质及颜色仍为 106 同款 `en SDF`；保留当前 RectTransform、字号和南瓜 Sprite Asset，独立 key 统一为 `S_LevelTips_Des_level_141_1`。
- 唯一 I2 模板只填简体中文，其他 75 个语言槽为空；两行包含已收集数量、南瓜内联图标和超越百分比。参数按位置传递：`{0}` 为收集数，`{1}` 为超越百分比，原有数字 link 标记与换行保持。按 131/132/134 的既有方式，由 Prefab 的 `LocalizeEvent` 调用公开 `FormatCollectedTranslation`，通过 `string.Format` 填入当前值后交回 TMP 排版；计数更新和语言刷新走同一回调。删除命名参数管理器，`AllowParameters=0`，不再传递参数名。
