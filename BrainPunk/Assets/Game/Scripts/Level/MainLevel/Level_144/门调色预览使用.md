# Level144 门调色预览

## 使用

1. 退出 Play 模式，打开 `Level_144.prefab`。选中右侧出口门 `door_0` 下的 **door** 子物体，即挂有 Spine 和 MeshRenderer 的可见门。
2. 在该物体的 **Spine Heat Tint** 组件中勾选 **开启编辑预览**。
3. 调整 **亮部颜色**、**暗部发光色**。拖动 **预览热度** 查看从原色到烧热的过渡：0 为原色，1 为最热。
4. 满意后保存 prefab。保存前会自动停止临时预览；保存的是两种颜色和运行时呼吸幅度，预览开关/预览热度不会写入玩法参数。继续调色时重新勾选预览即可。

「亮部颜色」给原图的亮部暖色乘色，「暗部发光色」给暗部补暖光，避免只压低绿色/蓝色导致纯红色块。两个颜色可输入 HDR 强度，但过高会洗掉线稿。呼吸幅度只用于运行时微弱发光变化，设 0 可关闭；编辑预览显示静态调色，方便对比。

预览作用于 Scene 视图中的真实门资源。停止预览、切换选择、保存场景/预制体、脚本重载或进入 Play 前，组件会恢复门原材质和原 PropertyBlock。编辑器预览不创建 GameObject/材质实例，不初始化 Level144 的运行时状态，不访问 DB、存档、RemoteConfig 或 Manager。

此入口按用户 2026-09-17 的最新要求调整：不使用 Tools 菜单或关卡根节点调色。变色实现、颜色数据都放在门上的脚本中，关卡只调用 `SetHeat` 传入热度。原有三个颜色/呼吸参数和四个资源引用原样迁移，地图与玩法规则不变。

## 文件及验证

- `SpineHeatTint.cs`：挂在变色物体上，持有颜色和资源引用；运行时和编辑预览共用同一套调色逻辑。
- `Editor/SpineHeatTintEditor.cs`：仅为该物体组件提供 Inspector 预览滑条及保存前恢复，无菜单或独立窗口。
- `Level144Ctrl.cs`：计算关卡热度并传入门上的组件，退出时请求恢复原色。
- `Resources/Level144HotDoor.mat`：本关专用 `Spine/Skeleton Tint` 材质，原门图集和其它关卡材质只读。

本轮证据见 `outputs/level144-20260917/revision2/`，执行结果汇总在本目录 `验证记录.md`。完整主游戏和真机手感仍需试玩。需要撤销本轮时使用该目录 `before/` 对照逐项恢复控制器、prefab 和编辑器脚本，移除新增变色组件及其 Inspector，保留后续人工调色值和其它用户编辑；不撤销先前 3/4 秒玩法修订。
