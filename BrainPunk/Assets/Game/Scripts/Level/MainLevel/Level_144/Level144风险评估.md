## 风险与处理

| 风险 | 处理与验证边界 |
| --- | --- |
| 旧风区推力或拖动组件同时响应 | 仅在 144 实例关闭风区/落叶、旧输入脚本和旧持久事件；一个本关输入状态机区分操作 |
| 原稿上下两组扇叶只有一组可操作 | 同时绑定两根中心骨骼，开始时选择最近一组；用真实 Spine 坐标验证 |
| 自动风扇误触发通关 | 自动最多降至 20% 热度，永久冷却状态只由连续手动时长写入 |
| 小抖动或穿过圆心误累计 | 最低角速度 8°/秒、中心死区、按住 0.3 秒容错，松手立即复位 |
| 暂停/后台仍在累计或留下循环声音 | CanRun 门禁及 Pause/Focus/Disable 清理，只停止本关持有的声音实例 |
| 受热被实现成时间倒计时 | 只按角色到出口碰撞盒边缘距离计算；测试固定距离多次更新不累积 |
| 原稿地图被重排或其它关卡变动 | 所有原有 Transform/图像引用静态比较；记录并核对受保护文件哈希 |
| 配置生成覆盖用户其它配置差异 | 原表只新增行，保留其它部件/样式；只复制两份对应 JSON，生成前后核对已有记录 |
| 本机 Excel 占用或并行编辑表格 | 保存前比对备份并同时取得两张表的写入能力；不能写入时保留产物、等待用户关闭，不强制结束 Excel |
| 隔离环境与主游戏不同 | 隔离测试使用真实 prefab/Spine，但游戏服务为桩；不宣称完整主游戏/实机通过 |
