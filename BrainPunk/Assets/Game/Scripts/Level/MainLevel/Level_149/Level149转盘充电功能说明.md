# Level 149 转盘充电功能说明

## 当前有效结论（2026-09-20）

左电量开场从0在2秒有效玩法时间内涨到20%后停止赠电；随后靠主角跑动继续充电。用户已明确确认这一规则，并取消截图中的 `l93GearRotate`。跑轮仅使用原 `step` 脚步，快跑0.16秒一次，慢走0.4秒一次。

左台仍从电池上实际起跳后吸附、按方向手动充电；右台靠近站稳后点击闪电按钮，自动向右跑一段并充入最多三分之一。右侧未满时停跑2秒后每秒衰减25个百分点，满电不衰减，但左右满电后都允许再次登台发电，电量仍封顶100%。推荐先左满再连续跑右侧，但没有先左后的门禁。

按钮登右盘与自动离台采用本关小弧线、idle姿态；自动结束不调用共享Jump。双满播放现有火箭爆炸及用户指定 `flyRocketExplosion`，笼子前后两层一起炸飞，完成后开放原钥匙。拾钥匙、飞钥匙、出口解锁及进门成功继续由共享链负责。

## 玩法与参数

### 开场和左台

1. Awake左/右均为0，左侧仅赠送一次总量0.2；默认 `initialChargeSeconds=2`。暂停/失焦/不可操作不推进，玩家提前充电可与剩余赠电相加，但总值封顶1。
2. 两块电池沿用单向承托；从电池上实际共享Jump后才有当前一跳的左台捕获资格，地面直跳和走下电池均不算。
3. 左台沿用0.22～0.32秒两段吸附：先保留入场速度减速，再平滑收进锁点；到位0.09秒落地拍。方向单按立即walk01并以0.25/秒充电；松手慢走不充电；双按视为无输入。
4. 左满后0.32秒小弧线返回这次电池起跳位置，到位才释放物理；电量封顶100%，仍接受之后从电池起跳的左台吸附；满电重新登台后可持续跑动，用跳跃键小跳离台。此自动离台不调用jumpForce=18；普通电池手动起跳仍使用既有Jump。
5. BoxPink沿用原逻辑：未失衡时慢走带盘，超过160度/秒后锁存单次die翻滚、眼睛独立转动，重开恢复。未改变其皮肤、盘面同步及电光基准。主角影子现由本关Actor实例关闭，见后续章节。

### 右盘按钮、自动跑与小跳离台

1. 按钮不检查左电量；未登台且进入 `boardDistance=2.2` 时显示，右满电也显示，实际站稳才允许进入。
2. 点击后0.2秒沿 `Lerp(start,anchor,t)+up*4*0.35*t*(1-t)` 小跳入盘。途中idle，不执行共享跳跃、不跑步、不充电。
3. 到位固定朝右walk01，盘面480度/秒，按0.25/秒最多充入1/3；完整一段约1.3333秒。方向不改变本段，Jump不能提前退出，按钮隐藏。
4. 保存本段目标电量，时间结束精确写回该目标。局部运行曾复现原浮点累计略低于1导致三段仍不开笼，此收口修正后第三段精确满电。
5. 结束仍保持接管，0.32秒沿附加弧高0.18的小弧线回到点击时地面位置，idle姿态，到位后恢复刚体、输入和原脚步组件；没有共享18力度向上弹射。
6. 右盘就位/跑动不衰减；结束后前2秒保持，随后每秒减少0.25，最低0。下一次登台清计时；满电后不衰减，离台后仍显示按钮；满电再次登台固定跑完整1/3对应时长（约1.3333秒），电量保持100%。左电量从不衰减。

### 双满炸笼与出口

1. 双满且尚未开笼时只触发一次：爆炸实例位于前栏可见中心，缩放0.7，SceneLayer/250，声音一次 `flyRocketExplosion`。
2. 前后笼体保持相对姿态，共同围绕中心按 `(6t,22t-7t²)` 飞离并旋转−330t度，持续 `cageBlastSeconds=0.8` 秒后停用两层。
3. 笼子飞走后才启用原钥匙Collider。钥匙原地保留，由共享拾取/飞钥匙/DoorLock/出口完成流程；炸笼不直接成功。
4. 粒子仅用本关有效dt手动模拟；暂停冻结，生命周期结束销毁。重开/失败/退出销毁本关实例，不能残留播放。
