# Level111「恢复异常」功能与风险记录

## 需求与确认口径

- 进入关卡时角色直接出现，不播放通用入口门演出。
- 玩家需要修复五处异常；全部修复后才显示场景中已有的 `Key`，后续沿用既有钥匙、门锁和出口门通关链。
- 门上半截拖到下半截附近后吸附对齐并替换成完整 `door_0`；无效投放回到初始异常位置。
- 必须先完成门体拼合，初始入口处的 `DoorLock` 才能放到 `door_0/LockPoint`；提前投放或投到其他位置都会复位，成功吸附后恢复为正向缩放。
- 左上角关卡牌初始只露出一半，向下拖到正常高度后吸附；无效投放复位。
- 商店按钮初始旋转 180°，玩家围绕图标中心单指旋转，接近正确角度后吸附；未达到容差则复位。
- 暂停与提示白色图标初始互换。实际按钮功能跟随白色图标，提示气泡也跟随提示图标；将任一图标拖到另一图标区域可交换回来，失败则回到异常位置。
- 每项修复成功时播放 `verifticationCorrect`，并显示绿色勾的弹性放大、停留、渐隐反馈。
- 用户明确要求：过关逻辑不确定时不得猜测。本实现没有新增替代通关条件。

## 实现结构

- `Level111Ctrl.cs`
  - 管理五项修复状态和完成反馈。
  - 运行时定位已摆好的 `Sp_l111_zs_01`、`Sp_l111_zs_02`、`door_0`、`DoorLock`、`Key`。
  - 完整门在拼门前隐藏，钥匙在五项全部完成前隐藏。
- 门碎片吸附时先只移动碎片，保持拖放时的旋转与缩放；碎片真正到达拼合点后，先在同一帧以接近原尺寸显示完整门，再隐藏两块碎片并以 `OutBack` 轻微回弹到原始大小，避免从 0 缩放造成一瞬间整扇门消失和闪烁。
- 五项状态全部完成后，既有 `Key` 固定在当前画面正中央以纵向拉伸、横向压缩、回弹复原的形变动画出现，完成形变后再垂直落到画面中央对应的地板高度；不再根据最后一个修复点计算轨迹。
- 钥匙落地动画期间暂时关闭其 Collider，落地后恢复原启用状态，避免半空中提前拾取；后续解锁链不变。
- Key Prefab 自带的 `MoveFloatHandle` 会持续改写钥匙位置；出现和下落期间临时禁用该组件，落地后再恢复，避免与出场动画争抢 Transform 造成抖动。
- Level111 场景中的 Key Prefab 实例还额外挂有 `isAutoPlay = true` 的 `ItemJumpOutExecutor`，激活钥匙时会启动随机水平偏移协程并与本关动画争抢位置；本关在初始化和显示钥匙前均停止其协程并禁用该组件，且落地后不再恢复。钥匙拾取、跳向门锁和解锁链保持原样。
- `Level111WorldDragItem.cs`
  - 负责门上半截和门锁的世界坐标拖拽、拖动层级提升、成功吸附及失败复位。
- `Level111UiGestureHandle.cs`
  - 把关卡牌、商店图标、暂停图标和提示图标的 EventSystem 手势转发给 Level111 控制器。
  - 暂停/提示白色图标在公共 HUD 中默认关闭 `Graphic.raycastTarget`；Level111 运行时临时开启以接收拖拽，修复完成或退出关卡时恢复原值。
  - 拖拽开始后，仅给当前拿着的白色图标临时挂载独立顶层 `Canvas`（最高 sorting order），确保它显示在暂停/提示按钮底板之上；吸附、失败复位或关卡销毁时移除并恢复原排序状态。
- `BaseLevelCtrl.cs`
  - 新增实例级入口演出开关，默认开启；Level111 在 `Awake` 中关闭，不改变其他关卡。
- `GamePlayPanel.cs`
  - 新增实例级暂停/提示功能交换开关，默认关闭，并在面板打开/关闭时复位；仅 Level111 异常状态启用。
- `Level_111.prefab`
  - 根节点控制器由复制遗留的 `Level7Ctrl` 替换为 `Level111Ctrl`。
  - 门上半截节点规范为 `Sp_l111_zs_02`。
  - 复用现有绿色勾 Sprite 和场景中已经摆好的门、门锁、钥匙位置。

## 运行时边界与恢复

- 暂停、提示、商店和关卡牌属于共享 `GamePlayPanel_000`。Level111 只在当前面板实例上临时改造，关卡销毁时恢复父节点、位置、旋转、缩放、按钮功能及点击阻塞状态。
- 提示气泡仍由原 `GamePlayPanelTipsSwitcher` 控制显示周期，只调整其运行时父节点，使视觉位置跟随提示图标。
- Level111 关卡代码不再查找、关闭或改写场景 `Tips` 的 I2 组件和文本；标题内容、I2 Term 与启用状态完全由 `Level_111.prefab` 的场景配置负责。当前 Prefab 仍保留复制来源 Level7 的词条与预览文本，等待场景侧按正式文案调整。

## 已知风险与调参入口

- 门半截吸附半径、门锁吸附半径和世界物件吸附时长在 `Level111Ctrl` Inspector 中可调。
- 完整门弹性出现时长、弹性起始比例，以及钥匙形变出现时长和垂直下落时长在 `Level111Ctrl` Inspector 中可调。
- 关卡牌高度容差、商店角度容差和 UI 复位时长目前是 `Level111UiRepairController` 常量；若实机手势偏严，可在脚本中调整。
- UI 异常使用共享面板的当前布局作为“正常姿态”快照；若公共面板层级或节点名改变，需要同步 Level111 的运行时查找路径。
- 当前 `Level_111.prefab` 的 `Tips` 仍保留复制来源 Level7 的 I2 Term 和预览文本；代码不再提供覆盖或兜底。场景侧完成正式 Term、预览文本与启用状态调整前，实际显示内容仍需复核。

## 回滚方式

- 从 `Level_111.prefab` 移除 `Level111Ctrl`，恢复原控制器引用即可停用本关玩法。
- 删除 Level111 三个脚本及其 `.meta`。
- 回滚 `BaseLevelCtrl` 的入口演出实例开关，以及 `GamePlayPanel` 的暂停/提示功能交换开关；两者默认关闭特殊行为，不回滚也不会影响其他关卡。
- 若仅回滚 2026-09-07 的文案归属修正，可恢复 `Awake()` 对 `ApplyLevelTitle()` 的调用及该方法；这会重新引入运行时代码关闭 I2、硬写中文标题的行为，不建议在场景侧配置完成后回滚。
