## 流程、验证和风险

- 只接受主角刚体且每局一次；先走现有失败事件，再由 Actor 子类停止输入/跳跃、关闭身体和推物体碰撞，持续下沉并在 0.4 秒内黑化。沿用约 1.2 秒后的 Failed Reset 重建，不新增存档/打点/全局事件。退出停止私有烟音、恢复实例颜色并注销订阅；普通移动继续沿用原 ActorCtrl。
- 烟雾每次最多 28 粒子，私有音源遵守 SfxOn；1.57 秒音效尾部会随原失败重建停止。四关共用的局部烧焦脚本本轮修复首次订阅未初始化空引用。
- 已完成本关完整 YAML 无重复/悬空 ID 检查、所有新绑定源组件核对、基础参数与原 overrides 一致性检查；隔离 C# 编译 0 错误。具体证据和工具输出限制见 [岩浆模块记录](../Level_9/Level009岩浆泡泡功能与风险记录.md)。
