# Level098 风险评估

## 2026-08-18 行为等价精简风险复核

- **事实**：停用和销毁原本都停止门上拉音并解绑事件；暂停标记仍留在停用专属路径。
- **直接结论**：声音停止、事件清理和暂停边界与原实现一致，不影响石像承托、门上拉和关卡结算。
- **假设**：无新增运行时假设；本轮为私有重复代码抽取。
- **缺失证据**：尚未执行 Unity PlayMode 的门上拉中断、暂停/恢复、重开及 Android/iOS 回归，标记为 `uncertain`。
- **回滚**：内联 `CleanupRuntimeState()` 即可。

## 已控制的风险

- 不按 `PlayerJumpEvent` 次数判负，避免“按了跳跃但实际未起跳”或“跳起后仍落入第五坑”被误判。判路以石像顶面承托和第五坑右侧地面承托两种物理结果收口。
- 门触发器从关卡初始化就封印，避免失败路线的角色在门上拉前抢先触发 `BaseLevelCtrl.OnActorTrigger2D`。
- 石像上升使用 Kinematic `Rigidbody2D.MovePosition`，而不是直接改 Transform；控制器在暂停、重置和销毁时停止本地推进并清理事件订阅。
- 相机逻辑不写入共享 `CameraFollowArea`，只在本关组件内锁定 Y/Z；启动后以角色 X 为目标，越过黄框时仍向边界收敛，避免 SmoothDamp 尚未到位就冻结。黄框垂直尺寸不参与运行判定，角色掉坑时镜头不会纵向跟随。
- 坑宽按真实空隙而不是把根坐标整体乘 `0.8`；平台尺寸不变，FallArea 的中心和横向尺寸同步复算，避免平台重叠或正确路线落点被失败区覆盖。
- 石像和门绳只复用现有声音 tag。门绳循环句柄在上拉完成、暂停、重置、Disable 和 Destroy 都会停止，不会把循环音带入重开或其它关卡。
- 所有状态和门禁均为本关实例字段，不新增全局事件、存档字段、配置字段、音频资源或资源加载路径。
