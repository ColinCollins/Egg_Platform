# Level128 风险评估

更新时间：2026-08-24

## 边界结论

手机当前时间适合作为趣味谜题答案，不适合作为安全凭据。代码读取的是玩家设备本地时间，玩家可以修改系统时间、时区或 12/24 小时显示；本关不把该值用于账号、付费、奖励防刷、排行榜或服务端校验，因此风险被限制在单关解谜体验内。

## 风险与处理

| 风险 | 处理与证据 | 状态 |
| --- | --- | --- |
| 输入过程中跨分钟导致正确答案失败 | 提交时接受当前分钟和上一分钟；不扩大到前两分钟或未来分钟 | 代码静态通过，PlayMode 待验收 |
| 玩家手机采用 12 小时制，线索未说明 24 小时制 | 同一时间同时接受 `HHmm` 与 `hhmm`；21:05 可用 `2105/0905` | 代码静态通过 |
| 凌晨或分钟含 0，原密码盘无法输入 | 本关专用弹窗在原 1 至 9 下方补齐 `* / 0 / #`，三个键都能写入显示；0 可组成时间，包含 `*` 或 `#` 的四位输入按错误密码处理 | 引用静态通过，布局待验收 |
| 玩家修改系统时间或时区绕过推理 | 这是预期可接受的本地谜题弱点；不把设备时间作为可信安全源 | 已接受的产品风险 |
| 关闭或 Reset 后旧成功任务仍开门 | 每次 Open/Close 变更会话版本，成功 await 后复核 `_isOpen`、版本与派发标记；关闭淡出期间保持输入锁定并忽略重复关闭 | 代码静态通过，时序待验收 |
| 连点第四位或重复回调多次派发成功 | 四位后立即锁输入，`_successDispatched` 保证事件 ID 1 只派发一次 | 代码静态通过 |
| 成功后重新进入密码区域再次打开弹窗 | 事件 ID 1 派发后由 `Level128Ctrl` 记录本次尝试已解锁，并对 `Use_btn` 同时设置 `IsBlockClick=true`、`Interactable=false` 和隐藏；重新绑定 HUD 时重放状态 | Roslyn/静态调用链通过，PlayMode 待验收 |
| 成功等待期间关闭弹窗却提前失去入口 | 成功入口锁只在事件 ID 1 真正派发时建立；关闭先使会话版本失效，不会触发锁定 | 代码静态通过，时序待验收 |
| 退后台跨分钟后沿用旧的半截输入 | 失焦或进入后台时清空未成功输入；提交时重新读取本地时间 | 代码静态通过，真机待验收 |
| 错误 Feedback 缺失或结束回调失效后卡在四位 | 缺失 Feedback 时立即清空；存在时按当前会话完成回调清空 | 静态绑定通过 |
| 第四行变成 4 列、横向撑开或压入底框 | 原 Grid 资产是固定 3 行，12 项时会自动排成 4 列；本关运行时明确改为固定 3 列、列数 3，View 和四行按键组统一等比缩到 `92%`，键盘上移 `12` 个局部单位；可见 `Bg` 整体再等比缩到 `95%`，最终底行距背景底部约 `46.51` | 静态边界通过，PlayMode/多分辨率 `uncertain` |
| 纵向拉长后背景边框变形 | 原背景为无 sprite border 的 Simple Image，纵向拉伸约 17.5% 会一起拉伸圆角和边框；本轮按“只纵向拉长”实现，若视觉不接受需另做 9-slice 资产 | PlayMode 视觉 `uncertain` |
| `*` 或 `#` 显示为缺字方框 | 按钮使用的 `en SDF` 未预烘焙这两个字符，但 Font Asset 为 Dynamic 且保留源字体，TMP 可走运行时补字形 | PlayMode/真机字形 `uncertain` |
| 修改 Level128 误伤 Level096 或四个 Trick 点 | 共享文件未改；场景相对 Level096 仅根名、控制器和暂停文本三类差异 | 静态通过 |
| Prefab 手工编辑导致 GUID/fileID 断链 | 两个 Prefab 均无重复定义或悬空引用；新增 meta GUID 唯一 | 静态通过，Unity 导入待确认 |
| 排序 ID 误写 128，导致连续解锁断层 | LevelSort 使用连续 ID 107，Path 才是 10128 | Excel/JSON 已验证 |
| 本地表与远端排序不一致 | 本地 Excel、JSON、Guru 默认值均追加 10128；线上启用的旧 RemoteConfig 仍需发布侧同步 | 本地完成，线上 `uncertain` |
| 结算或答案 key 缺失 | LevelData 已登记 Level128 专用 key，但未编造正式文案 | 本地化内容 `uncertain` |
| 连续 Reset 后旧门事件订阅残留 | 共享 `EventListenerExecutor` 在 `Awake` 订阅，但静态代码未发现销毁解绑；Level096 等既有关卡也使用该共享实现 | 既有共享风险，实际影响 `uncertain`，本关不跨级修改 |

## 验证证据

- `Level_128.prefab` 相对 Level096 的场景差异只有三类；四个 Box、四个占位 Tips、暂停位置与门事件链不变。
- Level Prefab 为 `245 refs / 0 missing / 0 duplicate`，密码弹窗为 `144 refs / 0 missing / 0 duplicate`；新增资源 GUID 均唯一。
- Excel 候选导出后重新导入，目标行值、既有区域、其它 Sheet 和公式均通过比较；Sheet 顺序、定义名称与既有 7 条批注语义保留，所有 Sheet 视觉检查通过，公式错误为 0。
- Luban 生成退出码 0；`tbleveldata.json` 和 `tblevelsort.json` 只增加目标记录，ID 与排序均唯一。
- Guru YAML/生成 C# 的默认排序 JSON 可解析，长度和末项一致。
- 当前 Bee `Assembly-CSharp.rsp` 使用 Unity Roslyn 完整编译为 0 error / 104 条工程既有 warning，Level128 诊断为 0；时间校验边界为 14/14 PASS。最新整体缩放与键盘上移后定向编译为 0 error / 0 warning，布局、动画目标与输入静态断言为 11/11 PASS。Unity Editor 正式程序集刷新、PlayMode 与移动端仍未执行，不得视为已通过。

## 发布前验收矩阵

- `09:05`：`0905` 可过；`0904` 作为上一分钟可过；`0903/0906` 不可过。
- `21:05`：`2105/0905` 可过；上一分钟 `2104/0904` 可过。
- `00:00`：`0000/1200` 可过；上一分钟 `2359/1159` 可过。
- 正确密码等待 1 秒期间关闭、Reset 或离开，不得开门；重复点击不得重复派发。
- 正确密码成功派发后，弹窗关闭且 `Use_btn` 不可再次打开密码页；离开再进入密码区域，即使按钮被共享显示逻辑重新激活也必须保持不可点击。
- 成功前关闭或 Reset，入口保持可用；成功后 Reset 或退出再进入 Level128，新关卡尝试恢复可用入口且不继承旧 `_passwordSolved`。
- 错误密码反馈结束后可重新输入；退后台再返回时半截输入已清空。
- `*`、`#` 点击后会写入四位显示；凑满四位后走错误反馈并清空，不应表现为无响应。
- 设置暂停页显示 `????`，其它暂停来源不显示；恢复、Reset 和离开后不残留。
- 四个 Box 仍可拖拽，门仍只在事件 ID 1 后执行原开门链。
- Android/iOS 横屏下 `95%` 整体面板、`92%` 内部显示区与按键组、`* / 0 / #`、关闭键和错误反馈无遮挡，上移后的底行不压入底框，整体缩放不引入非等比横向拉伸。

## 回滚

优先通过本关私有脚本调整分钟容错、12/24 小时兼容、键盘布局或成功入口锁，不修改共享 `PasswordPopup`。只撤回入口锁时移除 `Level128Ctrl` 中对应事件订阅与状态应用；完整撤回时删除 Level128 私有资产并移除 Excel、JSON 与 Guru 中唯一的 `10128 / 107` 配置；Level096 和共享系统无需跟随回滚。
