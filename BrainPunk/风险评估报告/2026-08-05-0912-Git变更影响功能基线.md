### DrawGame 主流程基线

- `LoadManager` 在配置加载后初始化 `GameManager.Instance.DrawGameLevel`，由 `DrawGameLevelCtrl.Init()` 读取 `TbDrawLevelSort`，非 Editor 环境下再应用远端 `drawgame_config.enabled` 与 `drawgame_config.level_sort`。
- `DrawGameLevelCtrl.LevelSorts` 是 Draw 选关、下一关、Level999 直达 Draw 的新排序入口。它会过滤缺失 sort/path 的远端项，并在末尾补齐 `20999`，用于最终 TBN 关卡。
- `GameManager.TryEnterDraw()` 负责打开 `DrawGame_ChoiceLevelPanel` 和 `DrawGame_GamePlayPanel`。`GameManager.TryEnterDrawLevel()` 进一步调用 `DrawPlayCtrl.OpenDrawLevelAsync()` 进入指定 Draw 关。
- `Level999Ctrl.EnterDrawGameAtHighestPlayableLevel()` 从 `DB.DrawGame.UnlockLevels` 与 `DrawGameLevelCtrl.LevelSorts` 推导最高可玩 Draw 关，再通过 `GameManager.TryEnterDrawLevel()` 进入。
- `DrawPlayCtrl.TryGetNextLevel()` 已从原始 `TbDrawLevelSort.DataList` 切换为 `GameManager.Instance.DrawGameLevel.LevelSorts`，因此远端排序、最终 TBN、选关显示与胜利后下一关共用同一链路。

### DrawGame Reset、Replay、广告与奖励墨水基线

- `DrawPlayCtrl` 现在用 `_isAttemptTransitionPending` 门禁统一管理失败 Reset、Replay、黑色 HUD 遮罩和输入恢复。
- 失败插屏从失败事件入口延后到 `ResetGameAsync(..., showFailureInterstitial: true)` 的重置准备完成之后触发，降低 Unity 原生覆盖层期间 PlayerLoop 停止导致黑屏的风险。
- Reward ink 改为只有 `AddInk()` 实际增加墨水时才设置 `_isRewardInkGranted`，并在新关卡、返回选关、Deactivate 时清理奖励会话。
- 未完成的验证基线：真实 Android/iOS 插屏回调、无广告回调、网络失败、后台恢复、Replay 连续点击、Reset 中断仍未由本次命令验证。

### DrawLineFeature 输入基线

- `DrawLineFeature` 支持区域外按下后拖入有效画线区域再开始画线。
- 输入会话由 pointer down/began 建立，拖入合法区域时才开启线条，pointer up/canceled 或禁用输入时清理会话。
- 风险基线：多点触控、从 UI 区域按下后拖入、应用后台导致缺失 release、每个低编号 Draw 关的碰撞区域和完成判定仍需要 PlayMode 覆盖。
