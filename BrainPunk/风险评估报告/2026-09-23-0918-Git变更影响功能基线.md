## OneLink 关卡跳转基线

### 职责与入口

- `GameSDKService` 初始化 OneLink；`GameAnalytics` 注册 AppsFlyer UDL hook；`OneLinkManager` 同时接收 `Application.deepLinkActivated` 与 AppsFlyer UDL。
- `StartPanel` 只在进入动画结束、启动弹窗派发完成、Main 场景、应用有焦点、无 Popup/Top/遮罩/关闭中 UI 且主控制器处于 START 时尝试导航。
- `OneLinkRequest` 白名单限制 action、game type 与 level path；`OneLinkLevelRouter` 将请求分发到主线、Draw 或 IWanner。
- AndroidManifest 当前可见 App Link 是 `https://brain.gurugame.ai/default_link`，未直接声明 `brainpunk.onelink.me`；短链是否通过服务端重定向抵达已声明域名需要部署证据。

### 状态与持久化链

- 主线：解析目标 → `UnlockLevel` → `EnterOneLinkMainLevel`。
- Draw：解析目标 → 打开选择面板 → `TryEnterOneLinkLevel`，该路径会更新当前/解锁状态后进入资源加载。
- IWanner：解析组与关卡 → 必要时写入 `UnlockGroups` 并保存 → `TryEnterIWannerGroup` → 异步打开关卡。
- `OneLinkManager.TryNavigate` 在调用路由前先把 `_pending` 置空（509-517 行）；路由拒绝或异常只记录日志，不自动恢复请求。
