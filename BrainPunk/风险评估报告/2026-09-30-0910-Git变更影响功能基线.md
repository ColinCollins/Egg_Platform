## OneLink 初始化与回调入口

- `GameSDKService.InitService()` 调用 `OneLinkManager.Initialize()`，随后 Guru analytics 创建 `GameAnalytics`。`GameAnalytics` 先注册 `GuruAppsflyer.Prepare(...)`，再注册 `OneLinkManager.AppsFlyerHook`。
- `AppsFlyerHook.Prepare()` 在 AppsFlyer `initSDK` 后、`startSDK` 前调用 `BindAppsFlyer()`；绑定 Unity `Application.deepLinkActivated`、AppsFlyer UDL 回调和 Guru conversion data Observable。
- 冷启动/热唤起 URL、AppsFlyer UDL、Guru GCD Observable 与 `GuruAppsflyer.ConversionData` 缓存快照是四类输入。缓存探测窗口为 5 秒，每 100 毫秒读取一次公开快照；GCD 有效目标最多等待 UDL 5 秒。
- UDL `ERROR` 的有 URL 恢复最多一次，总预算 10 秒，原生网络有效后才启动预算；iOS 无 URL 路径只复用已有/晚到的安装归因数据，不把重复注册回调当作重新拉取。

## URL、首页门禁与进关链

运行链为：

```text
Android VIEW / iOS Universal Link 或 URL Scheme
  -> Application.deepLinkActivated / AppsFlyer UDL
  -> OneLinkManager.IsRoutingUrl / TryParseUrlQuery / OneLinkRequest.TryParse
  -> pending request
  -> StartPanel.LateUpdate
  -> OneLinkManager.TryNavigateFromStartPanel
  -> 首页弹窗、Main 场景、焦点、UI 栈、PlayCtrl START 门禁
  -> OneLinkLevelRouter.TryEnter
  -> 各玩法 OnLevelEntryStarted / ConfirmLevelEntered / EndEntry
  -> GameData.OneinlinkEnterType / IsEnterByOneLink
```

- Android Manifest 注册 `brainpunk.onelink.me/IjED` 和可被外部应用调用的 `uribrainpunk` scheme；iOS `ProjectSettings.asset` 也注册 `uribrainpunk`。
- 短链交给 AppsFlyer 原生桥接；带明确 query 的 HTTP(S) 或 `uribrainpunk://link` 可走本地解析。
- 首页门禁不持有输入锁；玩家进入玩法后会丢弃待处理链接。`entry_accepted` 只表示路由受理，只有 `entry_completed` 才表示加载完成并保存玩法历史。

## 奖励、存档与事件链

`cdabfed29` 新增的奖励链为：

```text
deep_link_value=getCoin/getSkin
  -> OneLinkRequest.TryParseReward
  -> 首页门禁（可选 sub3 等待有效用户）
  -> ExecuteReward 再次核对目标 Uid
  -> GameData.OneLinkClaimedRewardIds 本地防重
  -> SimpleBag.AddTool / GetNewSkin
  -> GameData GameTools / OwnedSkin / WaitingPreviewSkinId
  -> UpdatePropEvent、皮肤红点、analytics
  -> DB.SaveGameData() -> PlayerPrefs
```

- `sub1` 是客户端提供的领取标识，`sub2` 是金币正整数或皮肤配置 ID，`sub3` 可选并只做当前 Guru Uid 等值比较。
- 当前没有签名、服务端验券、活动白名单或服务端原子领取；清档、换设备、存档回滚和更换 `sub1` 都不受本地列表约束。
- 金币先做 `int` 溢出检查，皮肤先验证配置存在；领取标识和奖励最终保存在同一份 `GameData`。
- `SimpleBag.AddTool(GameProps, ...)` 会调用字符串重载；字符串重载和枚举重载当前各派发一次同样的 `UpdatePropEvent`。金币余额只增加一次，但 UI/事件消费者收到两次通知。
- `OneLinkClaimedRewardIds` 为永久 `List<string>`，查重是线性 `Contains`，每次领取后保存整份 `GameData`，没有活动分桶、过期或容量上限。
