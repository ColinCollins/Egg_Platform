## 受影响功能基线

### 1. Play Controller 切换与 GM 调试命令

- 入口职责：`PlayControllerManager.TryEnter` 负责按 `PlayModeType` 选择策略、初始化目标玩法 Controller、停用上一个 Controller、激活目标 Controller，并在异常时尝试恢复上一个 Controller。
- 最近变更：`IGMFeature` 成为 GM 上一关、下一关、直接胜利的统一能力边界；`GMPanel` 不再直接判断 `PlayCtrl`/`DrawPlayCtrl` 类型，而是读取当前活动 Controller 的接口能力。
- 当前链路：`GMPanel` 按钮 -> `PlayControllerManager.CurrentController` -> `IGMFeature.TryEnterPreviousLevel/TryEnterNextLevel/TryForceVictory` -> 各玩法 Controller 本地处理。
- 风险边界：GM 命令现在只作用于活动玩法。Main 保留主线关卡跳转与 `EnterLevelEvent`；Draw 明确拒绝上下关；IWanner 使用当前 Group 内小关语义。历史依赖“非活动主线兜底”的调试脚本或自动化不再成立。

### 2. IWanner 新玩法入口与运行时

- 入口职责：`StartPanel/WannerGameEnter` 通过 `IWannerGameEnter` 读取 `ConfigManager.RemoteConfig.GetIWannerGameIsOpen()`，开启时调用 `GameManager.TryEnterIWannerFirstGroup()`。
- 控制器链路：`GameManager` 注册 IWanner policy/controller -> `PlayControllerManager.TryEnter(PlayModeType.IWannerGame, context)` -> `IWannerPlayCtrl` 加载 `WannerLevel` prefab -> 创建 `IWannerGame_GamePlayPanel` -> 注入当前 `IWannerLevelCtrl` 成功、死亡、Reset、Replay 回调。
- 资源链路：`Assets/BPGame/AssetBundleCollectorSetting.asset` 新增 `Assets/Game/Prefabs/WannerLevel` 收集；`ILevel_001.prefab` 至 `ILevel_005.prefab` 是当前可见运行资源。
- 数据链路：`IWannerGameLevelCtrl.Init()` 在 Loading 配置完成后读取 `Tables.TbIWannerLevelData` 与 `Tables.TbIWannerLevelSort`，缓存数据并校验首个 Group；当前 JSON 证据显示 LevelData 共 21 条，Sort 共 4 个 Group，Group path 为 5 个小关引用。
- UI/事件链路：HUD 方向和跳跃复用既有玩家输入事件；Reset 使用 `IWannerGameResetEvent`；Replay 复用 `GameReplayEvent`，由活动 IWanner Controller 判断当前 Group 语义。
- 风险边界：IWanner 目前是横跨主界面、Loading、资源收集、Luban、RemoteConfig、UI、事件、Controller 的新运行链路。是否完成 Android/iOS 横屏、资源包构建、真实入口开关、失败/胜利全链路回归仍未由本次命令验证。

### 3. RemoteConfig 与 Guru 默认配置

- 入口职责：`RemoteConfigService.RemoteConfigKeys` 当前包含 `level_config`、`drawgame_config`、`iwannergame_config`；启动拉取和批量默认值写回会遍历这些 key。
- 最近变更：`iwannergame_config` 独立接入 Guru YAML、`GuruAllSpecs.G.cs`、`ConfigManager.RemoteConfig` getter、`GMRemoteConfigDisplay`。
- 当前读取规则：运行态优先读取远端/缓存 `iwannergame_config` 字段；缺失时回退 `GlobalConst.IWannerGame*`；非运行态直接回退默认值。
- 已知限制：`TryValidateRemoteConfigValueVersion` 只验证 `level_config`；`iwannergame_config` 当前不包含 `enabled` 或 `currentRemoteConfigVersion` 字段；默认 `iWannerGame_IsOpen` 当前为 true。
- 风险边界：当远端 key 缺失、字段缺失、旧缓存存在或 Guru 默认落盘时，IWanner 入口开关的来源需要专项验证，不能仅凭代码存在判断发布安全。
