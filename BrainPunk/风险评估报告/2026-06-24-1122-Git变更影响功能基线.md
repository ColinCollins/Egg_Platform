## PlayCtrl 免费皮肤弹窗与存档链

### 本次 Git 入口

- commit `f9f54a0ad4d23691fa380ee12cb1311faf6655d6db361b34`：`GetSkinPopup 显示`
- commit `9b5e001da56287e6a237feb4b9ebb50bc42016a2`：`GetSkinPopup level 条件限制`
- 直接文件：`Assets/Game/Scripts/Play/PlayCtrl.cs`、`Assets/Game/UI/GetSkinPopup/Scripts/GetSkinPopup.cs`

### 功能职责

- `PlayCtrl.OnEnterLevelLoadingEraseComplete()` 在关卡 loading 擦除完成后调用 `TryToGetFreeSkin()`。
- `TryToGetFreeSkin()` 从 RemoteConfig 读取免费皮肤触发关卡和皮肤 id；当前关卡不匹配或已拥有时跳过。
- 命中条件后查 `TbSkin` 并调用 `GetSkinPopup.Create(data)`。
- `GetSkinPopup.Create(Skin data)` 打开弹窗后立即调用 `GrantSkin(data, RewardType.Other)`，向 `DB.GameData.OwnedSkin` 添加 skin id 并 `Save()`。
- 弹窗负责展示皮肤名和 icon；icon 通过 Bear `ResourceManager.CanLoad<Sprite>()` / `LoadAsync<Sprite>()` 读取 `Assets/Game/ArtSrc/Skins/UI/{TextureResources}.png`。

### 影响链路

- 关卡进入主流程 -> PlayCtrl loading 完成 -> RemoteConfig 免费皮肤配置 -> GetSkinPopup 打开 -> `OwnedSkin` 写入并保存 -> 后续 ShopPanel Skin 和 Actor Skin 绑定读取已拥有皮肤集合。
- 该链路直接触达 P0 哨兵 `PlayCtrl`、RemoteConfig、DB/存档和皮肤资源加载。

### 验证状态

- 已静态确认触发关卡限制、已拥有跳过、皮肤表查找、弹窗 grant/save 和 icon 异步加载路径。
- 未验证 RemoteConfig 默认值、弹窗打开失败时是否仍应 grant、移动端资源包是否含目标 icon。
