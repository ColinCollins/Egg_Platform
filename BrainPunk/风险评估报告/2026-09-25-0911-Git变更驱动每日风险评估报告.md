## 变更入口到影响链路

### OneLink/SDK/平台链

`Android App Link / iOS Universal Link / Unity deepLinkActivated / AppsFlyer UDL-GCD / GM 参数`
→ `GameSDKService.InitializeAsync()` 与 `GameAnalytics` 转发
→ `OneLinkManager` 合并、重试、去重、游戏中丢弃、首页排队
→ `LoadManager` 启动弹窗序列和 ChestGift 跳过
→ `StartPanel + UIManager.HasBlockingPopup` 可见性/遮罩门禁
→ `OneLinkLevelRouter`
→ 主线/Draw/IWanner 解锁与选择存档
→ 各玩法异步资源加载
→ `ConfirmLevelEntered` 写每玩法一次历史
→ 胜利 UI 根据来源隐藏 Replay。

### 主线异步竞态链

旧请求 A `PlayCtrl.CreateLevelAsync()` await 资源
→ 控制器退出仅 `EndEntry(Default)`，不取消 A
→ 新请求 B 重新 `TryBeginEntry(Default)` 并 await
→ A 晚到
→ A 仍按 `GameType.Default` 调用 `ConfirmLevelEntered` 或 `EndEntry`
→ B 的来源标记和历史被提前写入或清空
→ 胜利 Replay、每玩法一次配额、当前 LevelCtrl 与后续失败处理可能归属错误。

### Draw 远端排序链

`RemoteConfigService` 获取 JSON
→ `DrawGameLevelCtrl.TryBuildRemoteConfigCandidate`
→ 缓存成功后 `ApplyRemoteConfig` 增加 `ConfigGeneration`
→ `DrawGame_ChoiceLevelPanel` 刷新和拒绝过期选择
→ OneLink Draw Router 查最终排序
→ 写 `DB.DrawGame.CurrentLevel/UnlockLevels`
→ `DrawPlayCtrl` 资源加载、Loading 遮罩和成功确认。

### IWanner 修正链
