- 功能职责：
  - `Postcard_Star` 在收集成功后写入 `DB.Postcard.LevelVictoryStar`，调用 `DB.SavePostcard()`，发放 `GameProps.Star`，并派发 `PostcardGetStarEvent`。
  - `PostcardManager` 订阅 `PostcardGetStarEvent`，按当前 `PlayCtrl.Instance.Level.CurrentLevelData.Id` 累加 `DB.Postcard.LevelCollectedStar`，并在胜利面板创建时由 `GameVictoryPanel` 一次性消费并清理。
  - `PostcardEnter` 在运行时读取 `ConfigManager.RemoteConfig.IsOpenPostcard()`；关闭时隐藏入口，开启时绑定按钮打开 `PostcardPopup`。
- 依赖链：
  - prefab 星星触发器 -> `Postcard_Star` -> `DB.Postcard.LevelVictoryStar` / `DB.SavePostcard()` -> `PlayCtrl.Instance.Bag.AddTool(GameProps.Star, 1, RewardType.Other)` -> `PostcardGetStarEvent` -> `PostcardManager` -> `DB.Postcard.LevelCollectedStar` -> `GameVictoryPanel.CachePostcardCollectedStarCount()`。
  - `PostcardEnter` -> `ConfigManager.RemoteConfig.IsOpenPostcard()` -> `level_config.isOpenPostcard` -> `GlobalConst.IsOpenPostcard` fallback。
- 已知边界：
  - `PostcardEnter.OnEnable()` 已有 `Application.isPlaying` 外层防护，避免编辑器态读取 RemoteConfig。
  - `Postcard_Star.TrySaveCollectionAndReward()` 在 `DB.SavePostcard()` 失败时移除已加入的 index，避免永久收集记录部分写入；金币/星星奖励只在保存成功后发放。
  - `PostcardManager.ConsumeCollectedStarCount()` 清理失败时仍返回本次读到的计数，用于避免阻断胜利面板表现；这意味着清理失败可能导致下次重复消费，需要 PlayMode/存档失败注入验证。
