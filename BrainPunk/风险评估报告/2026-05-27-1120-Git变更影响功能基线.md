## Level56 FlipBird 主线

- 入口：
  - `Assets/Game/Prefabs/Level/Level_056.prefab` 中触发器回调 `OnActorEnterFlipBirdArea`
  - UI 面板 `Assets/Game/UI/GamePanel/Resources/GamePlayPanel_019_56.prefab`
- 关键职责：
  - `Level56Ctrl` 负责玩家进入触发区后的主流程切换、锁 X、启动小游戏、监听成功/失败回调。
  - `Level56FlipBirdGameCtrl` 负责滚动背景、刷柱子、计时和成功回调。
  - `Level56GamePanelCtrl` 负责隐藏左右移动按钮和 `1000m -> 0m` 距离表现。
- 关键依赖：
  - `ActorCtrl`
  - `PlayCtrl.Instance.CurrentGamePlayPanel`
  - `ObjectPoolManager<Level56PipeObstacle>`
  - `Level_056.prefab` 内的 `scrollTargets`、`pipePrefabs`、`spawnRoot`、`finishPoint`、`door`
- 当前调用链：
  - TriggerArea -> `Level56Ctrl.OnActorEnterFlipBirdArea()` -> `StartFlipBird()`
  - `StartFlipBird()` -> `panelCtrl.SwitchMoveBtns(false)` + `panelCtrl.StartGoal()` + `flipBirdGame.SetActor()` + `flipBirdGame.StartPlay()`
  - `Level56FlipBirdGameCtrl.Update()` -> `elapsedTime >= gameDuration` -> `FinishGame(true)` -> `OnSuccess`
  - `Level56Ctrl.OnFlipBirdSuccess()` -> `flipBirdGame.StopPlay()` + `panelCtrl.StopGoal()` + `door.position = finishPoint.position`
- 当前对照点：
  - 当前代码把 `MoveActorToFinishPoint()` 注释掉，成功后是移动 `door` 而不是移动 `actor`。
  - `Level56GamePanelCtrl.StopGoal()` 当前只停 UI，不负责恢复左右移动按钮。

## Level57 乌鸦 / 水位 / UI 跟随碰撞体链

- 入口：
  - `Assets/Game/Prefabs/Level/Level_057.prefab`
  - 乌鸦点击回调 `Level57Ctrl.ClickCrow(...)`
- 关键职责：
  - `Level57Ctrl` 负责乌鸦朝向、水位上升、点击产出粪便。
  - `ShitPoolCtrl` 用 `ObjectPoolManager<ShitItem>` 管理粪便池。
  - `Level12SceneItemsCtrl` 把 `GamePlayPanel_DragButtons` 转成世界空间 `Ground` 碰撞体。
- 关键依赖：
  - `Level12SceneItemsCtrl.WorldColliders`
  - `goldShit.prefab` / `normalShit.prefab`
  - `ActorSpineCtrl`、水体节点、`BuoyancyEffector2D`
- 当前调用链：
  - 玩家点乌鸦 -> `Level57Ctrl.ClickCrow()` -> `SpawnShit()` -> `ShitPoolCtrl.Spawn()`
  - `ShitItem` 自身带 `Rigidbody2D + Trigger BoxCollider2D`
  - `Level57Ctrl.Start()` 延迟执行 `AddRigidbodiesToWorldColliders()`，给 `Level12SceneItemsCtrl` 生成的 UI 跟随碰撞体补 `Rigidbody2D`
  - 粪便入水 -> `OnShitEnterWater()` -> 抬高水位
- 当前对照点：
  - `WorldColliders` 原始来源是跟随 UI 拖拽按钮位置变化的 `Ground` 代理碰撞体。
  - 当前代码对这些代理碰撞体补的 `Rigidbody2D` 没有显式设置 `bodyType / gravityScale / constraints`。

## 启动 / RemoteConfig / Guru level_config 链

- 入口：
  - `LoadManager.Awake()` 队列中的 `LoadConfigAsync()`
  - `Assets/Guru/guru_spec.yaml` / `Assets/Guru/Gen/GuruAllSpecs.G.cs`
- 关键职责：

  - `LoadManager` 负责启动期清缓存、拉配置、初始化首登奖励。
- 关键依赖：
  - `DB.GameData.RemoteConfigCache`
  - `DB.GameData.CurrentAppVersion`
  - `LevelCtrl` / `InterstitialAdPolicy` / `GameTipsPopup` / `GameVictoryPanel` / `TransformPopup` / `ShopAdRewardTipAutoShowModule`
- 当前调用链：
  - `LoadManager.LoadConfigAsync()` -> `RemoteConfigService.TryToClearRemoteCache()` -> `UpdateRemoteConfigsForLoadManager()`
  - `RemoteConfigService.UpdateRemoteConfigsAsync()` -> `ConfigManager.RemoteConfig.SetRaw(level_config, json)` -> `DB.GameData.RemoteConfigCache`
  - 运行时多个模块通过 `ConfigManager.RemoteConfig.Get*()` 读取广告、提示、首登奖励、胜利奖励倍率等
- 当前对照点：

  - `level_config` 当前新增了 `initGameCoinReward`。
