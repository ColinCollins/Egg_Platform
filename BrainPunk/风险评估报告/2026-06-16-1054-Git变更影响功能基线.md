## 1. ShopPanel Skin 浏览、解锁与预览

### 功能职责

本次主要功能入口来自 commit `d66580fa3266e5d35923e166e64b2cbd5d8fbcf8`：`Implement ShopPanel skin preview flow`。

- `Assets/Game/UI/ShopPanel/Scripts/ShopPanel_SkinPart.cs` 现在负责皮肤目录过滤、列表刷新、点击选择、默认皮肤归属补齐、广告/金币/内购解锁、存档写入、角色预览刷新和场景 `Skin` 根对象显隐。
- `Assets/Game/UI/ShopPanel/Scripts/InfiniteScrollView.cs` 是 ShopPanel 本地的 `ScrollRect` 有界复用槽位组件，负责有限/循环模式、可见槽位计算、content 尺寸、滚动回调与 `SkinItem` 绑定。
- `Assets/Game/UI/ShopPanel/Scripts/SkinItem.cs` 是单个复用槽位绑定组件，负责清理旧视觉状态、写入皮肤名/品质背景/选中态/解锁状态，并把点击转发给当前绑定的 `Config.Skin`。
- `Assets/Game/UI/ShopPanel/Scripts/ShopPanel.cs` 在 `OnClose()` 调用 `ShopPanel_SkinPart.HideSceneSkinPreview()`，作为 ShopPanel 关闭时隐藏场景级预览的兜底。
- `Assets/Game/UI/Global/Scripts/UISpineCtrl.cs` 新增 `SetCombinedSkin(IEnumerable<string>)`，用于把基础皮肤和背部/脸部/身体局部 Spine skin 合并到 UI skeleton。

### 入口与调用链

1. 玩家打开 ShopPanel。
2. ShopPanel 显示 Skin 分区时启用 `ShopPanel_SkinPart.OnEnable()`。
3. `ShopPanel_SkinPart` 读取 `ConfigManager.Instance.Tables.TbSkinShop` / `TbSkin`，按 all/back/face/body 过滤后传给 `InfiniteScrollView.SetData(...)`。
4. `InfiniteScrollView` 根据 viewport 和 `constraintCount` 创建或复用 `SkinItem` 槽位，并在滚动时调用 `BindSkinItem(...)`。
5. 玩家点击 `SkinItem`：
   - 已拥有：直接写入 `DB.GameData.CurrentBackPart` / `CurrentFacePart` / `CurrentBodyPart` / `CurrentSkinName` 并保存。
   - 广告：走 `RewardAdHelper.TryToShowRewardAd(RewardPlacement.ShopReward.ToString())`，成功后 `GrantSkin(...)`。
   - 金币：检查 `PlayCtrl.Instance.Bag`，用 `RemoveTool(GameProps.Coin, price, CostType.Other)` 扣费后 `GrantSkin(...)`。
   - 内购：用 `Products.GetProductId(...)`、`GameSDKService.Instance?.IAP_CLK(...)`、`GameManager.Instance.Purchase.Purchase(...)` 进入 IAP 回调。
6. 应用皮肤后 `ApplyCurrentSkinToViewer()`：
   - 对局部部件调用 `ApplyBoxerPartAsync(...)`。
   - 通过 `Config.Skin.PrefabResource` 直接校验 YooAsset location 并用 Bear resource system 加载 prefab。
   - 通过 `UISpineCtrl.SetCombinedSkin(...)` 或 `SetSkin(...)` 刷新 UI skeleton。
