## 关键调用与状态基线

### IAP 恢复链

`ShopPanel.Restore` -> `PurchaseManager.Restore()` -> 平台 `RestorePurchases()` -> `OnRestored(AssetStore)` -> `ResolveRestoredProductNames()` -> Android 自动或 iOS 手动 `SyncRestore()` -> `TryRestorePurchase()` -> Bag / PurchaseCache / Save。

- 当前 iOS 通过 `_assetStoreVersion` 最多等待 10 秒获取本轮 AssetStore 通知。
- `ResolveRestoredProductNames()` 在本轮 AssetStore 为空时提前返回，不清除上次 `_restoredProductNames`；随后 `OnRestored()` 仍递增版本。
- 新 `newno_ads` 与旧 `no_ads` / bundle 的运行时识别入口已同时保留；新购买入口切换至 `newno_ads`。

### ChestGift 购买链

Entry / Popup -> `ChestGiftController.TryPurchase()` -> SDK 购买 -> `OnPurchaseResult()` -> `PurchaseManager.OnPurchaseSuccess()` 先写 PurchaseCache -> `TryDeliverRewards()` 发 Coin / Skin -> `RecordDeliveredOffer()` 写完成商品 -> GiftManager 刷新。

- `GiftData` 当前版本为 2，新增当日 offer 日期、档位、商品、刷新次数与完成商品字段。
- 版本 1 升级到版本 2 时无法重建升级当天此前 offer 历史，项目文档已把该点标为待真机/跨天验证。
- PurchaseCache、Coin/Skin 与 GiftData 完成标记不是同一个事务。

### IWanner 新组链

`LevelSort.xlsx` 组 15 -> `tbiwannerlevelsort.json` -> ChoiceLevel Item 状态 -> `IWannerPlayCtrl` 入口门禁 -> `ILevel_071` 至 `ILevel_075` Prefab -> Actor / Door / Camera / FallArea / Feedback。

- 组 15 当前 `isBoss=true`、`lockType=1`；代码对 Boss 组始终返回 Normal 状态并允许进入。
- `IWannerGame_MoveListener` 新增 `isOnce`；`ILevel_074` 显式启用，既有 `ILevel_034` 仍引用同一共享脚本且缺省为关闭。
