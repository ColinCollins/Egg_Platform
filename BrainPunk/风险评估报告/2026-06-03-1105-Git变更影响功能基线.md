## 功能职责与调用链基线

### Level64 关卡交互

- 入口：`Level_064.prefab` 挂接 `Level64Ctrl`、`Level64BlockCtrl`、`SpriteDragRotate` 与关卡 actor。
- 角色链：`ClickStartDoor()` 克隆 `actor`，设置移动输入、tag/layer、缩放，并在 `Update()` 中逐个调用 `tool.OnUpdate()`。
- 旋转链：`Level64Ctrl.Start()` 订阅 `dragRotate.OnAngleChanged`，角度达到 `SpriteDragRotate.GetMaxAngle()` 后触发 `OnDragRotateReachedMax`。
- 方块链：`Level64BlockCtrl.Start()` 注册 `Level64BlockItem` 对象池并生成 output 方块；`OutputTriggerEnter()` 从 output 堆取出方块；`InputTriggerEnter()` 把方块放入 input 堆；`OnDestroy()` 回收并注销池。
- 当前断点：`OnPlayerEnterOutputArea()` 在 `HEAD` 为裸 `blockCtrl` 语句，当前工作区改成 `// TODO`，尚未把玩家触发区接到 `OutputTriggerEnter()` / `InputTriggerEnter()`。
- 影响标签：游戏主线核心流程、资源加载、关卡 prefab、对象池、状态/回调。

### RemoteConfig / 启动配置

- 入口：`LoadManager.LoadConfigAsync()` 依次调用 `RemoteConfigService.TryToClearRemoteCache()`、`UpdateRemoteConfigsForLoadManager()`、`ConfigManager.Instance.InitializeAsync(...)`。
- 拉取链：`RemoteConfigService.UpdateRemoteConfigsAsync()` 调用 `RemoteConfigManager.Instance.ForceFetch()`，最多等待 10 秒；失败、超时或 `LastFetchStatus != Success` 时切换 fallback。
- fallback 链：优先读取 `DB.GameData.RemoteConfigCache`，再读取 `GuruSdk.Instance.RemoteConfigSpec.DefaultValues`，最后通过 `ConfigManager.RemoteConfig.SetRawBatch()` 写回 DB cache。
- 清缓存链：版本不一致时 `ClearRemoteCache()` 清 `DB.GameData.RemoteConfigCache`，更新 `CurrentAppVersion` 并保存，再把当前 spec default 写回 cache。
- 业务读取：广告频控、胜利奖励、提示消耗、初始金币、公告开关、GAPS、关卡排序等通过 `ConfigManager.RemoteConfig.GetXXX()` 读取。
- 影响标签：RemoteConfig、DB/存档、SDK 初始化、广告、界面弹窗、游戏主线核心流程。

### VictoryPanel 分享 / 奖励 / 打点

- 入口：`PlayCtrl_Success.OnEnter()` 通关后触发插屏、`LevelEndEvent`、Rating 判断，再调用 `GameVictoryPanel.Create(owner.Level.CurrentLevelData, !hasPassedCurrentLevelBefore)`。
- 奖励面板：首通打开 `GameVictoryPanel_Reawrd`；`OnClickAdReward()` 调用 `RewardAdHelper.TryToShowRewardAd(GameVictory)`，成功后 `GrantRewardCoins()` 按 `HorizontalRandomAdRewardCtrl.GetCurrentReward()` 发金币并自动进入下一关。
- 分享奖励：`GameVictoryPanel_Share.GrantShareReward()` 读取 `GetLevelVictoryShareCoinReward()`，通过 `PlayCtrl.Instance.Bag.AddTool(... RewardType.Media)` 发金币，并写入 `DB.GameData.HasSharedLevel`。
- 反应打点：like/dislike 调用 `GameSDKService.Instance.LevelVictoryReaction(levelPath, bool)`，上报关卡反应数据。
- 影响标签：界面弹窗、广告、打点数据统计模块、DB/存档、奖励路径。
