## 变更入口到影响链路

### 1. `PlayCtrl.cs` / `GameData*.cs` 为什么会影响主流程

- 变更意图：
  把首关 `BeginerPopup` 从静态资源接到实际进关链，并用 `HasBegineTutorial` 存档位防重入。
- 影响链路：
  `EnterLevelEvent -> PlayCtrl.OnGameEnter -> EnterGame -> ShowBeginerPopup(3s延迟) -> BeginerPopup.Create -> DB.GameData.HasBegineTutorial -> SwitchGameStateEvent(PAUSE/PLAYING)`
- 扩散原因：
  它不只是加了一个 popup，而是直接插入 `PlayCtrl` 状态机和首关入场顺序，任何暂停恢复、首关动线、首进存档判断都会跟着变。

### 2. `WaitingPopup.cs` 为什么会影响广告和 IAP

- 变更意图：
  给等待窗加 3 秒后可手动关闭、超时关闭和 DOTween 显示动画，并复用到奖励广告等待和 IAP 流程。
- 影响链路：
  `RewardAdHelper.TryToShowRewardAd -> WaitingPopup.SetOnCancel -> WaitingPopup.WaitingAdLoad -> GameSDKService.ShowRewardAd`
  `PurchaseManager.Purchase/Restore -> WaitingPopup.Create(false) -> 用户手动关闭 -> 后台请求继续`
- 扩散原因：
  `WaitingPopup` 是所有异步购买/广告请求的共用遮罩，行为一改会同时影响广告取消语义、IAP 遮罩时机、商店等待体验和重复点击风险。

- 变更意图：
  把入关开门演出挂到每次 `CreateLevelAsync` 后，并从多个 `StartDoor` prefab 查找/回填控制器。
