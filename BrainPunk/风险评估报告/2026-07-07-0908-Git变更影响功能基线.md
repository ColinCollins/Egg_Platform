## 功能职责与调用链基线

### Postcard 存档与页面流

- `Postcard` 使用 `StorageType.PlayerPrefs`，运行时由 `DBManager.LoadDataForInstance(...)` 读取 `SaveData_Postcard`，再调用 `BaseSaveDataSO.FromJson(json)`，该方法使用 `JsonConvert.PopulateObject(json, this)` 填充实例。
- `PostcardPopup` 通过 `DBManager.Get<Postcard>()` 读取当前明信片数据；`SaveCurrentId(...)` 写入 `DB.Postcard.CurrentId` 后调用 `DB.SavePostcard()`。
- `Postcard_PageItem` 在玩家点击解锁 item 时先写入 `CurrentCollectedPuzzledId`，如果整页完成则写入 `CompletedId` 并清空当前页收集列表；`DB.SavePostcard()` 成功后才调用 `Bag.RemoveTool(GameProps.Star, ...)`。
- `PostcardPopup_PageCompleteProcess.OnPageComplete()` 当前顺序为：设置交互锁 -> 刷新 Chest -> 等待 0.5 秒 -> 隐藏 Chest -> 等待 0.5 秒 -> 打开 `CommonGetRewardPopup` 并等待关闭回调 -> 等待 0.5 秒 -> 自动切下一页并保存 `CurrentId`。

### Postcard 配置与资源

- `PostcardConfig` 当前字段为 `PrefabPath`、`ThemeName`、`UnlockProgress`、`Rewards`、`RewardMultiple`。
- `tbpostcardconfig.json` 当前使用 `Postcard_ocean`、`Postcard_forest`、`Postcard_food`、`Postcard_ems`、`Postcard_universe`、`Postcard_museum`、`Postcard_unlock` 作为 `prefabPath`。
- `PostcardPopup` 使用 `Resources.Load<Postcard_PageItem>(PrefabPath)` 加载页面 prefab，缺失 `Postcard_PageItem` 时拒绝切页并记录 warning。
- 当前 `themeName` 普通页为空，`Postcard_unlock` 为 `???`，标题实际显示仍依赖后续配置和 I2 词条验证。

### 红点系统

- `RedDotManager` 使用静态字典维护状态、父子关系、checker 和 UI 监听；`RedDotView` 在 PlayMode 的 `OnEnable()` 订阅，在 `OnDisable()` 退订。
- `PostcardRedDotRegister` 注册 `RedDotKey.Postcard`，但本次静态搜索未发现项目内实际调用 `RedDotRegisterHub.RegisterAndRefresh(...)` 或 `RedDotManager.Register(...)` 注册该业务。
- `PostcardRedDotChecker` 判断链路为 `DBManager` 初始化 -> `Postcard.CurrentId` 有效 -> 当前 `CompletedId` 未完成 -> `TbPostcardConfig.GetOrDefault(CurrentId)` -> `PlayCtrl.Instance.Bag.GetToolCount(GameProps.Star)` -> `UnlockProgress` 中存在未收集且 Star 足够的 puzzle。

### 通用奖励弹窗关闭回调

- `CommonGetRewardPopup.Create(...)` 现在可接收 `Action callback`。
- 回调存入 `_closeCallback`，在 `OnClose()` 中调用 `InvokeCloseCallback()`；调用前会先置空字段，避免同一实例重复触发。
- Postcard 完成页流程依赖该回调继续自动切页，因此关闭路径、外部销毁路径和异常路径都属于验证重点。

### 关卡选择明信片星星

- `LevelData` 新增 `LevelSumStarCount` 和已有 `LevelVictoryStarCount`。
- `PlayCtrl_Success` 使用 `LevelVictoryStarCount` 作为首次通关默认明信片星星发放数量。
- `Postcard_ChoiceLevelStarGroupCtrl.Refresh(...)` 使用 `LevelSumStarCount` 控制 Toggle 显示数量，再用 `PostcardManager.GetLevelCollectedStarIds(levelId)` 点亮已收集数量。
