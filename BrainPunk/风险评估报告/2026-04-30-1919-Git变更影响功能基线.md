## 本次变更入口

### 构建裁剪与类型保留链
- 入口：`Assets/Editor/ClassCollectorEditorWindow.cs`、`Assets/Editor/BuildPipline/BPGameCustomBuildDelegate.cs`、`Assets/link.xml`、删除的 `Assets/Game/Scripts/Generated/ClassCollector.cs`。
- 职责：构建前扫描运行时脚本类型，生成 `link.xml`，避免 IL2CPP/Managed Stripping 裁剪运行时脚本、SDK 反射类型、Timeline/Physics2D 类型。
- 调用链：构建流程 `BPGameCustomBuildDelegate.OnBeforeBuildStart` -> `ClassCollectorEditorWindow.TryRunAutoCollection` -> `GenerateLinkXML` -> `AssetDatabase.Refresh` -> YooAsset 内置包构建。
- 当前基线：静态 `ClassCollector.cs` 已删除，运行时类型保留主要依赖构建前自动生成 `Assets/link.xml`。当前 `link.xml` 只命中 `Level999Ctrl`，未命中最近新增或变更的 `Level44Ctrl`、`Level45Ctrl`、`ActorRandomSpineCtrl`、`Level47Ctrl`。

### 启动加载与热更新链
- 入口：`HotReloadCtrl`、`HotReloadCtrl_*` 状态节点、`LoadManager.HotReload`。
- 职责：初始化 YooAsset 包、请求版本、更新 manifest、下载补丁、清理缓存、进入游戏。
- 调用链：`LoadManager.Awake` 队列 -> `HotReloadCtrl.Instance.Init` -> 状态机 `INITIALIZE_PACKAGE` -> `REQUEST_PACKAGE_VERSION` -> `UPDATE_PACKAGE_MANIFEST` -> `CREATE_DOWNLOADER` -> `DOWNLOAD_PACKAGE_FILES` -> `START_GAME` -> `HotReloadCtrl.SetFinish`。
- 当前基线：失败节点会 `SetFailed`；`LoadManager` 最多等待 30 秒，并在失败时继续走后续配置和主流程，文案仍输出 `timeout (60s)`。

### 关卡进入、重开与资源加载链
- 入口：`PlayCtrl.EnterGame`、`PlayCtrl.OnEnterNextLevel`、`PlayCtrl.ResetGame`、`PlayCtrl.CreateLevelAsync`、`EnterLevelLoading`。
- 职责：设置当前关卡，播放进关转场，加载 `Assets/Game/Prefabs/Level/{level}.prefab`，创建玩法 UI，切换状态机。
- 调用链：`EnterLevelEvent/EnterNextLevelEvent/GameResetEvent` -> `EnterLevelLoading.Create` 或 `ResetGame` -> `DestroyLevel` -> `ResourceManager.LoadAsync<GameObject>` -> `BaseLevelCtrl` -> `GamePlayPanel.Create` -> `GamePlayStateName.PLAYING`。
- 当前基线：进关和下一关已按 `CreateLevelAsync` bool 结果 gate；`ResetGame` 仍未检查 bool 结果，也未捕获 `ResourceManager.LoadAsync` 抛出的异常。
