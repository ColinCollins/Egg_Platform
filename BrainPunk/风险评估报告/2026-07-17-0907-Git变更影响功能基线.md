- 最近提交：`4620eb9c5 LevelRuntimeState 结构补充优化`

### 原行为基线

- `GameTipsGuideFlow.cs` 原本是空 `MonoBehaviour`，不接管游戏主流程。
- `PlayCtrl_Playing` 原行为主要负责关卡运行、提示按钮警告与状态 tick，不在每帧触发一次性 Tips 引导流程。
- `GameTipsPopup` 原行为按金币或广告路径使用提示，并通过 `UseTipsEvent` 让关卡/运行状态记录提示使用事实。
- `GamePlayPanel` 原本承载 Tips 按钮、弹窗入口和面板生命周期，不只作为引导引用提供者。
- `GameData` 中新增的一次性标记 `HasTriggeredGameTipsGuide` 会把引导是否触发写入存档；当前改动链路中该标记在引导正式完成前写入。

### 当前行为基线

- `PlayCtrl_Playing.OnUpdate()` 达到配置等级、时间与失败次数条件后，只在当前 Playing 状态内尝试一次 `owner.TryStartGameTipsGuide(...)`。
- `PlayCtrl` 持有 `_gameTipsGuideFlow`，负责开始、取消、跨状态清理，并在引导期间派发 `GamePlayPanelSwitchBlockEvent(true/false)` 阻挡或恢复游戏面板输入。
- `GameTipsGuideFlow.ExecuteAsync()` 从 `RemoteConfig` 读取触发配置快照，检查关卡、进入关卡时间、失败次数、目标 UI、`CanStart` 和存档状态。
- 引导开始时通过 `TryMarkGuideTriggered()` 设置 `DB.GameData.HasTriggeredGameTipsGuide = true` 并保存，再依次执行开场对白、手指点击 Tips 按钮、打开首次免费 Tips 弹窗、免费使用提示、等待过关弹窗关闭，最后可选播放结束对白。
- `GamePlayPanel` 当前只提供 `TryGetGameTipsGuideTargets()` 与 `OpenFirstGuideFreeTipsPopup()`，生命周期关闭时通过 `PlayCtrl.Instance?.CancelGameTipsGuideFor(this)` 反向通知主控制器取消。
- `GameTipsPopup` 新增首次引导免费模式：准备免费按钮文案、启用免费按钮、调用 `UseFirstGuideFreeHint()` 走提示使用路径，并通过 `WaitForFirstGuideCloseByXAsync()` 等待关闭按钮关闭弹窗。

### 扩散链路

`PlayCtrl_Playing.OnUpdate()` -> `UpdateGameTipsGuide()` -> `PlayCtrl.TryStartGameTipsGuide()` -> `RunGameTipsGuideAsync()` -> `GamePlayPanelSwitchBlockEvent` -> `GameTipsGuideFlow.ExecuteAsync()` -> `DB.GameData.HasTriggeredGameTipsGuide / DB.SaveGameData()` -> `GuideDialogue.ShowAsync()` / `GuideFinger.WaitForClickAsync()` -> `GamePlayPanel.OpenFirstGuideFreeTipsPopup()` -> `GameTipsPopup.CreateFirstGuideFree()` -> `UseTipsEvent` -> `PlayCtrl.OnTipsUsed()` / `LevelRuntimeState.HasTips` -> 关卡成功/过关弹窗 -> 关闭弹窗后的结束对白。

### 下次对照要点

- 缺失或异常远端配置是否应禁用引导，而不是以 0 作为等级、时间、失败次数默认值。
- `HasTriggeredGameTipsGuide` 是否应在引导真正完成后写入，避免对白、手指、弹窗任一失败导致永久跳过。
- `hasCheckedGameTipsGuide` 在目标无效或 Tips 按钮未显示时是否允许重试。
- `GamePlayPanelSwitchBlockEvent(false)` 是否覆盖所有取消、异常、切关、重玩、销毁路径。
- 免费提示路径是否与普通金币/广告提示共享了关卡状态、打点与资源消耗边界。
