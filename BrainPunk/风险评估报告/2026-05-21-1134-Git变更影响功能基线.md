### 当前职责

- `LoadManager.EnterGame()` 在 `DBManager.Initialize()` 之后注册 `DailyScheduleModule`，并立即执行 `ScheduleSystem.CheckAllModules()`。
- `DailyScheduleModule` 当前内置持有两个子模块：
  - `InterstitialNOAdPopupAutoShowModule`
  - `ShopAdRewardTipAutoShowModule`
- `GameSchedule` 持久化三类数据：

  - `Daily_shopFreeCoinShowCount`
- `GMDailyScheduleTestController` 通过 GM 页提供“写昨日 UTC 0 点 + 立即 CheckAllModules”与“直接刷新 Daily 数据”的调试入口。

### 依赖与扩散链

- `Loading.unity -> LoadManager.EnterGame() -> ScheduleSystem.RegisterModule(new DailyScheduleModule()) -> DailyScheduleModule.CheckAndRefresh() -> DB.GameSchedule / DB.SaveGameSchedule()`
- `GMPanel -> GMDailyScheduleTestController -> EnsureDailyModuleRegistered() -> ScheduleSystem.CheckAllModules() -> Daily 子模块计数重置`

### 本次变更后需要持续对照的点

- Daily 子模块是否只由 `DailyScheduleModule` 持有，而不是各业务再各自 new 一份。
- `GameSchedule` 的每日计数是否只在真正弹窗展示后增加。
- GM 调试按钮是否只驱动 `Daily` 时间戳与计数，不绕过真实入口。
