## IWanner 选组与资源加载基线

- 配置入口是 `Assets/Game/Configs/tbiwannerlevelsort.json` 与 `Assets/Game/Configs/tbiwannerleveldata.json`，源表为 `Luban/Configs/Datas/LevelSort.xlsx` 与 `Luban/Configs/Datas/LevelData.xlsx`。
- `IWannerGameLevelCtrl.Init()` 从 `ConfigManager.Instance.Tables.TbIWannerLevelSort.DataList` 建立 `_levelGroups`，并用 `TbIWannerLevelData` 校验每个 Group 的 `path` 是否存在 LevelData。
- `IWannerGameLevelCtrl.TryGetLevelData()` 只校验 LevelData 行，不校验 `Assets/Game/Prefabs/WannerLevel/<path>.prefab` 是否已纳入 Git 或资源构建。
- `IWannerPlayCtrl.TryEnterGroup()` 通过 `CanEnterGroup()` 检查 Boss、已通关、当前 Group、`lockType == Unlock`、`DB.IWannerGame.UnlockGroups` 后进入小关。
- `ResolveCurrentGroupId()` 在无有效存档时返回配置首个 Group，因此 Group 1 即使 `lockType=1` 仍可作为 Current 入口；非当前 Group 的进入依赖通关推进或广告解锁存档。
- 结算文案链路为 `tbiwannerlevelsort.json.congraktTips` -> `IWannerPlayCtrl` -> `IWannerGame_GameVictoryPanel.Create/Reward.Create` -> I2 本地化资源。

## IWanner 角色与关卡控制基线

- `ActorCtrl` 是共享 Actor 基类，`GroundCheckDirection` 默认向下，`HandleCollision()` 的 BoxCast 和 Gizmo 绘制使用该方向。
- `Actor_IWanner` 继承 `ActorCtrl`，新增或使用 `SetGroundCheckDirection()`、`PreserveCurrentGroundCheckDirection()`、重力方向单向平台检测、沿 Ground 方向的最大坠落速度限制。
- `IWannerLevelCtrl` 订阅 `PlayerJumpEvent`，调用 `Actor_IWanner.TriggerGroundedJump()`；成功门吸附通过 `SnapActorToSuccessDoor()` 使用序列化 `actorOffset`。
- `IWannerGame_GravityCtrl` 订阅 `PlayerJumpEvent`，控制 `AreaEffector2D.forceAngle/enabled/forceMagnitude`，并把区域力方向同步到 `Actor_IWanner.SetGroundCheckDirection()`。
- `ILevel058Ctrl` 是 058 关局部脚本，等待跳跃事件后旋转 Actor、停止移动、设置区域力并唤醒 Rigidbody2D。
- 当前引用扫描显示 `Actor_IWanner.cs` 与 `IWannerLevelCtrl.cs` 各被 66 个 IWanner prefab 引用，其中包含 `ILevel_001` 到 `ILevel_050` 的 50 个已有关卡 prefab；共享行为变动会扩散到 50 以内关卡。

## RemoteConfig 与 DrawGame 基线

- `RemoteConfigService.UpdateRemoteConfigsForLoadManager()` 是 Loading 期远端配置入口，使用 `RemoteConfigKeys` 拉取 `level_config`、`drawgame_config`、`iwannergame_config`。
- 当前代码恢复 `RemoteConfigManager.ForceFetch()`，最多 2 次，每次等待 `ObserveConfigGetter().Skip(1)` 最长 35 秒，并要求 `LastFetchStatus == Success` 且 `LastFetchTime >= forceFetchStartedAtUtc` 才视为新鲜结果。

- `DrawGameLevelCtrl.SyncRemoteConfig()` 当前只在 `!Application.isPlaying` 时返回；PlayMode 内会读取 `drawgame_config` 并替换 Draw 关卡排序。
