## 变更入口到影响链路

### 链路 A：启动与配置

`LoadManager` 加载 Dig JSON → `GameManager` 初始化 `DigGameLevelCtrl`/`DigPlayCtrl` → `DigGameLevelCtrl.Init()` 校验类型、建立字典、补初始解锁并保存 → StartPanel 刷新入口。

- 失败扩散：配置缺失、主键重复或类型不符可阻断 Dig 初始化；存档保存失败只记录日志，内存状态仍继续。
- 资源关联：Excel → 生成 C#/JSON → 资源收集 → 运行时配置路径。

### 链路 B：首页到 Level 1

`DigGameEnter.OnEnable()` 订阅点击 → `DigPlayCtrl.TryEnterCurrentLevel()` → `EnterLevelLoading` → 创建 Dig HUD → `LoadAssetAsync(Assets/Game/Prefabs/DigLevel/{Path}.prefab)` → 实例化、绑定、初始化 → 揭幕 → `SwitchGameStateEvent(PLAYING)`。

- 当前工作区扩散：两个激活入口实例分别订阅点击，带来重复/重叠 UI 和未来维护分叉风险。
- 资源失败：Prefab/Bundle 地址、序列化引用或 UI 创建失败会中断进入；本轮没有真实 Bundle 验证。

### 链路 C：输入、碰撞与胜负

触摸/鼠标输入 → Actor 移动与 `DigTerrainCtrl.Stamp()` → Tilemap 逐格移除 → `ProcessTilemapChanges()` → 物理接触/吞噬动画 → 病菌数和待完成动画清零 → `TrySucceed()` → 结果回调。

- 当前 Prefab 细分 6：57,600 个碰撞格；初始化/重置为整块填充，笔画为逐格修改并刷新 Collider。
- 扩散对象：帧耗、内存、GC/Tilemap 物理重建、移动端触摸、暂停恢复和结果时序。

### 链路 D：成功、DB 与奖励

成功结果 → 冻结关卡/HUD → 按是否首胜创建奖励/普通面板 → 面板创建成功 → `RecordVictory()` 修改通关/解锁/当前关 → `DB.SaveDigGame()`。

- 首胜广告：点击 → 请求锁 → `RewardAdHelper.TryToShowRewardAd()` → SDK 回调 → 成功发币/刷新面板 → 解锁。
- 分享：平台分享调用 → `Bag.AddTool()` → `SharedLevelIds.Add()` → `DB.SaveDigGame()`。
- NoAds：点击 → IAP 请求锁 → `IAP_CLK`/购买回调 → 成功/失败恢复。
- 失败边界：保存失败不回滚；广告/IAP 若无结果回调，源码未见超时解除请求锁。

### 链路 E：打点与统计

Dig 进入/结果/Reset/Replay → 当前只切换本地玩法状态，没有 `level_start`/`level_end`/`b_play` → 现有 Main/Draw/IWanner 跨模式累计统计不包含 Dig → KPI、成功序号、时长与相关成就/分析存在口径缺口。
