## 功能基线：启动配置与远程配置缓存

- 入口：`LoadManager.LoadConfigAsync()` 在配置表初始化前执行远程配置加载。
- 关键链路：`LoadManager.LoadConfigAsync()` -> `RemoteConfigService.TryToClearRemoteCache()` -> `RemoteConfigService.UpdateRemoteConfigsForLoadManager()` -> `RemoteConfigService.UpdateRemoteConfigsAsync()` -> `ConfigManager.RemoteConfig.SetRaw()` -> `DB.GameData.RemoteConfigCache`。
- 持久化：`DB.GameData.RemoteConfigCache` 存 remote key 原始 JSON，`DB.GameData.CurrentAppVersion` 记录上次应用版本。
- 本次变化：版本不一致时先清空 `RemoteConfigCache` 并保存，再拉取新的 remote config。
- 影响标签：启动加载、远程配置、广告/打点/关卡排序/奖励配置、DB 存档。
