## 1. RemoteConfig / GlobalConst / Guru 默认配置链路

### 职责

- `RemoteConfigService` 在启动期通过 `RemoteConfigKeys` 拉取 `level_config`，失败或超时时回退到 `DB.GameData.RemoteConfigCache` 或 `GuruSdk.Instance.RemoteConfigSpec.DefaultValues`。
- `LoadManager.LoadConfigAsync()` 先调用 `RemoteConfigService.TryToClearRemoteCache()`，再执行 `UpdateRemoteConfigsForLoadManager()`，最后初始化 `ConfigManager`。
- `ConfigManager.RemoteConfig` 将远端原始 JSON 写入 `DB.GameData.RemoteConfigCache`，运行时业务通过 `TryGetValue(LevelConfigKey, fieldKey, out value)` 单字段读取远端值；无法读取时回退到本地 `TbGlobalConst`。
- `LubanGenerator` 的 `Export GlobalConst To Guru/guru_spec.yaml` 菜单把 `lubanconfig_tbglobalconst.json` 中指定字段同步到 `Assets/Guru/guru_spec.yaml` 的 `level_config` 单行 JSON。

### 本次变更入口

- 最近三天 commit：
  - `b9fc5bfa`：GMPanel 增加 clear remote config 入口，并改动 `GameData`、`ConfigManager.RemoteConfig`、`RemoteConfigService`。
  - `32759a57`、`cdfb79f2`、`857d48d4`：RemoteConfig 拉取、成功判定、批量落盘、失败回退逻辑调整。
  - `a39781d0`：`LoadManager.InitGameReward()` 对老用户负金币补零。
- 当前未提交变更：
  - `Assets/Configs/Code/LubanConfig/GlobalConst.cs` 新增 `currentRemoteConfigVersion`、`showVersionBoard` 强类型字段。
  - `Assets/Game/Configs/lubanconfig_tbglobalconst.json` 新增对应默认值。
  - `Assets/Game/Editor/LubanGenerator.cs` 将这两个字段加入 `GlobalConstLevelConfigKeys`，并移除 `guru_spec.yaml.bak` 同步菜单。

### 运行时入口和依赖

- 启动链路：`LoadManager.LoadConfigAsync()` -> `RemoteConfigService.TryToClearRemoteCache()` -> `RemoteConfigService.UpdateRemoteConfigsForLoadManager()` -> `ConfigManager.Instance.InitializeAsync()`。
- 数据链路：`RemoteConfigService` -> `ConfigManager.RemoteConfig.SetRawBatch()` -> `DB.GameData.RemoteConfigCache` -> `ConfigManager.RemoteConfig.TryGetValue()`。
- 默认值链路：`lubanconfig_tbglobalconst.json` -> `GlobalConst.cs` -> `ConfigManager.Tables.TbGlobalConst`；以及 `LubanGenerator` -> `Assets/Guru/guru_spec.yaml` -> `GuruSdk.Instance.RemoteConfigSpec.DefaultValues`。
- 受影响业务标签：启动配置、广告参数、胜利奖励参数、提示消耗、评分弹窗、公告弹窗。
