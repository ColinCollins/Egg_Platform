## DrawGame 主流程基线

- 入口与顺序：`LoadManager` 初始化 `GameManager.Instance.DrawGameLevel`，`DrawGameLevelCtrl.Init()` 从 Luban `TbDrawLevelSort` / `TbDrawLevelData` 建立关卡顺序；非 Editor 包体中 `SyncRemoteConfig()` 可读取 `drawgame_config.level_sort` 覆盖本地顺序。
- 选关入口：`DrawGame_ChoiceLevelPanel.OnOpen()` 读取 `DB.DrawGame`、修复首关解锁和当前关卡，刷新分页与关卡按钮；点击项后通过 `GameManager.Instance.DrawPlay.TryEnterLevel()` 进入关卡。
- 加载入口：`DrawPlayCtrl.TryEnterLevel()` 解析 `DrawLevelSort.Path` 对应的 `DrawLevelData.Path`，经 `ResourceManager.LoadAsync()` 加载 prefab，在 `Scene` 下实例化后查找 `IDrawLevelRuntime` 并调用 `InitializeRuntime()`。
- 运行链路：`DrawPlayCtrl` 负责相机切换、DrawGame 游戏面板、绘制输入、墨水、重置、重玩、失败、胜利、进入下一关、返回选关和运行时清理。
- 资源依赖：Draw 关卡 prefab 必须存在可加载路径、可绑定脚本、`IDrawLevelRuntime` 实现、运行时引用、碰撞体/画线区域/机关引用和胜负回调；`link.xml` 需要覆盖通过资源和 prefab 间接依赖的运行时类型。

## DrawGame 存档与配置基线

- `DB.DrawGame` 使用 PlayerPrefs 存储，记录当前关卡、最大关卡、已解锁、已通关、选关页、每关播放/成功/复活/时长统计、插屏间隔、星级、分享、Reaction、铅笔皮肤等状态。
- `DrawGameLevelCtrl.TryUnlockAllLevels()`、选关面板首关修复、等待关解锁和关卡完成流程都会写入 `DB.DrawGame` 并调用 `DB.SaveDrawGame()`。
- `RemoteConfigService` 当前只对 `level_config` 执行版本校验；`drawgame_config` 不在版本校验列表内。设备端 remote sort 与 Editor 本地 sort 可能出现差异。
- 影响标签：游戏主线核心流程、UI 主流程、DB/存档、远端配置、打点数据统计模块、广告。

## DrawGame UI 与广告基线

- `DrawGame_GamePlayPanel` 承载 DrawGame 局内 UI、墨水、提示、重置、暂停等交互。
- `DrawGame_GameTipsPopup` 同时承载提示和跳关变体；提示链路使用金币或激励视频，跳关链路使用金币或 `RewardPlacement.InGamePassLevel` 激励视频，成功后回调当前 `DrawPlayCtrl`。
- `DrawGame_GameVictoryPanel` 使用星级、分享、下一关、重玩、奖励选择等状态；下一关和重玩分别派发 `EnterNextLevelEvent` 与 `GameReplayEvent`。
- `DrawPlayCtrl.OnGameResetEvent()` 会进入失败/重置流程，调用 Draw 插屏策略并禁用输入；该链路与当前未提交 FusionAds 依赖降级存在交集。
