## Level62 fragile platform / block selection

### 已确认事实

- `Assets/Game/Scripts/Level/LevelItem/Level_62/Level62BlockItemCtrl.cs` 的 `SetSelected(bool)` 会在选中时调用 `fragilePlatform.SetAutoBreak(false)`，取消选中时调用 `fragilePlatform.SetAutoBreak(true)`。
- `Assets/Game/Scripts/Level/LevelItem/Level_62/SpriteRenderFragilePlatform.cs` 当前用 `BreakState.Intact / Breaking / Consumed` 表示平台状态，碰撞或 trigger 命中后通过 `BeginBreak(...)` 关闭 collider、启动 DOTween 渐隐，并根据 `destroyAfterSeconds` 延迟销毁。
- `SpriteRenderFragilePlatform.SetAutoBreak(false)` 会调用 `SuspendBreak()`，终止未完成 tween、恢复 collider，并把仍有效的 `_breakTarget` 放回 pending 集合；`SetAutoBreak(true)` 会通过 `TryBreakPendingTarget()` 重新检查目标是否仍接触后再破碎。
- `Level_062.prefab` 中存在多个 `fragilePlatform` 序列化引用，说明脚本变更会通过 prefab 资源链扩散到 Level62 运行时平台对象。

### 影响链路

玩家触摸或框选 Level62 block -> `Level62Ctrl` 命中 `Level62BlockItemCtrl` -> `SetSelected` 切换 `SpriteRenderFragilePlatform.autoBreak` -> 物理碰撞/trigger 回调进入 `TryBreak` / `BeginBreak` / `TryBreakPendingTarget` -> collider 可用性、透明度 tween、销毁时机变化 -> Level62 通路、卡关和重开一致性风险。

### 待验证

- Unity PlayMode 需要验证：选中瞬间已有碰撞、取消选中仍接触、拖框多选、重复点选、重开、失败和退出时 tween/collider 状态是否复位。
- Android/iOS 横屏需要验证触摸选择命中、物理回调顺序和帧率。
