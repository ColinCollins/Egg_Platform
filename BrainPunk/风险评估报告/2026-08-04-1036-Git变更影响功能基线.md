## 2. DrawPlayCtrl 功能基线

- `DrawPlayCtrl` 是 DrawGame 控制器生命周期入口，负责 Draw 选关、DLevel 加载、HUD 创建、暂停、重置、Replay、胜利结算、广告插屏策略、奖励墨水、每日挑战和 analytics。
- 当前 Reset 链路：
  - `DrawGameResetEvent` 仅在 Draw 控制器激活期间订阅。
  - `OnGameResetEvent()` 先设置 `_isAttemptTransitionPending`，取消胜利异步流程，调用当前 HUD 的 `BeginResetTransition()`，记录 retry/failed analytics，更新 Draw 插屏失败计数，再进入 `ResetGameAsync(..., showFailureInterstitial:true)`。
  - `ResetGameAsync()` 先关闭 Popup，等待黑幕淡入窗口，再调用 `ReloadCurrentLevelAsync()`。
  - `ReloadCurrentLevelAsync()` 销毁并重建 DLevel/HUD，在新运行时完成 `PlayResetIntroAsync()` 后才通过 `WaitForFailureInterstitialAsync()` 请求 `InGameFailed` 插屏，随后派发 `GamePlayPanelFadeInEvent` 并恢复 Drawing。
- 当前胜利链路：
  - `OnLevelResolved(Success)` 更新 Draw 插屏胜利计数，请求 `InGameVictory` 插屏，并启动胜利流程。
  - `RunVictoryProcessAsync()` 使用正数 `DrawLevelData.Id` 记录 DailyChallenge；失败解析时只记录 warning 并跳过。
  - 胜利星数通过当前关卡墨水状态计算并记录。
- 基线风险边界：
  - 插屏 SDK 成功、失败、拒绝、永不回调、切后台和横屏恢复尚未由本次自动化验证。
  - Reset/Replay/Victory 的 `_isAttemptTransitionPending` 是避免竞态的关键门禁，任何后续改动都应检查它是否成对释放。

## 3. DrawLevelCtrl 与 DrawLineFeature 功能基线

- `DrawLevelCtrl` 是每个 DLevel 的运行时桥接层，管理 Draw 输入、失败监听、成功/失败结果锁、局部 Intro/Reset、提示、墨水状态和 GameplayPanel 交互锁。
- 当前结果锁基线：
  - `TryResolve()` 同一尝试只接受第一次成功或失败。
  - `TryBeginSuccessPerformance()` 在成功演出前锁输入和 GameplayPanel，完成后由 `CompleteSuccessPerformance()` 正式提交。
  - `TryFailAndReset()` 提交失败后派发 Draw 专用 `DrawGameResetEvent`，不派发主线 `GameResetEvent`。
  - `IsOutcomeLocked` 暴露只读状态，供局部机关避免在结算期覆盖角色状态。
- 当前失败链路基线：
  - 运行时监听主线复用的 `OnTriggerTrapEvent` 与 `OnTriggerFailAreaEvent`。
  - 陷阱先调用 `_actor.Die()` 并等待死亡演出；失败区域播放 `failed` 并短等待；最终走 `CheckFinished()` 与 Draw 专用 Reset。
- 当前成功链路基线：
  - `OnTriggerSuccess()` 仍为成功门入口。
  - `TryTriggerSuccessWithoutDoor()` 用于篮筐、目标区等无 door_open 动画的关卡，复用 Actor 身份校验与渐隐，但不播放开门。
- `DrawLineFeature` 当前基线：
  - `tipsObjects` 是唯一提示对象列表，Reset 按对象分别恢复初始显隐。
  - `TryGetCompletedStrokeObject()` 供 DLevel 局部机制接管已完成线段。
  - `ContactFilter2D.useTriggers = true` 让 Trigger 也可参与画线阻挡判断，Draw Layer 仍被排除。

## 4. DrawGame HUD 与墨水条功能基线

- `DrawGame_GamePlayPanel` 是 Draw HUD，订阅：
  - `DrawInkStateChangedEvent`
  - `DrawGameCountdownChangedEvent`
  - `GamePlayPanelFadeInEvent`
  - `GamePlayPanelSwitchBlockEvent`
- HUD 不再直接订阅 Reset/Replay 事件；只有 DrawPlayCtrl 接受请求后才调用 `BeginResetTransition()`。
- 奖励墨水链路：
  - 点击奖励按钮后通过 `RewardAdHelper.TryToShowRewardAd(RewardPlacement.InGameTips)` 请求激励视频。
  - 回调通过 `_rewardAdRequestVersion` 淘汰过期请求。
  - 成功后调用 `DrawPlayCtrl.TryGrantRewardInk()`，并由 `DrawGame_InkProcessHandle.SetInkState(..., animateReward:true)` 播放宽度与填充动画。
- `DrawGame_InkProcessHandle` 当前基线：
  - `ConfigureStages()` 按 `DrawInkState.Stage / MaxInk` 生成或复用星级阈值节点。
  - `SetRewardPresentationExpanded()` 将背景、条底和填充宽度按奖励状态扩展。
  - `PlayRewardAnimation()` 使用 DOTween `SetUpdate(true)`，完成后刷新星级达标状态。
