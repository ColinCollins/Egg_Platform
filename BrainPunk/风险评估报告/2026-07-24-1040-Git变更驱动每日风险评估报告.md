- 建议：恢复 `[SerializeField] private float straightSuccessDelay = .5f;`，或明确迁移为统一常量并删除 prefab 残留；优先对前 50 关跑成功/重开/胜利面板回归。
- Git 依据：`136e0566f` 把 `[SerializeField] private float straightSuccessDelay = .5f;` 改为 `private float straightSuccessDelay = .5f;`；`c390b1dff` 对多关 prefab 增加 `straightSuccessDelay: 1.2`；`rg` 显示 `BaseLevelCtrl.cs:414` 仍读取该字段。
