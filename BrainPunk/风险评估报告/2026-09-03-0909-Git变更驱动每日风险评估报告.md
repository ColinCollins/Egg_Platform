## 变更入口到影响链路

1. 首页礼盒入口链路
   - `StartPanel.OnOpen()` 刷新 `DailyChestGiftEnter`。
   - `DailyChestGiftEnter.RefreshForHome()` 调用 `GiftManager.ConfirmHomeReached()` 并刷新按钮。
   - `GiftManager` 转发到 `ChestGiftController`，后者读取 `GameSchedule`、Resources prefab、`TbShop`、`TbProducts` 与 `PurchaseCache`。
   - 点击后进入 `ChestGiftPopup.RefreshOffer()`、`PurchaseManager.Purchase()`、IAP 点击打点、购买成功回调、Coin 发放、`NotifyGiftDelivered()` 与当日隐藏。

2. Shop typed reward 链路
   - `tbshop.json` 的 reward param 由 `BaseParamUtils.TryGetIntParam()` 等入口解析。
   - `PurchaseManager` 当前只把 `IntParam` 组装成 `Dictionary<GameProps,int>`；`StringParam` 不进入通用购买发放。
   - `ShopPanel`、`ShopItem`、`ShopRewardTipPopup` 的展示/奖励发放也主要依赖 `IntParam`。

3. IWanner 34-37 链路
   - 关卡排序/资源加载进入 `ILevel_034` 至 `ILevel_037`。
   - prefab 上的监听器收到 Bear 输入事件。
   - `IWannerGame_MoveListener` 将左右移动和跳跃全部转为同一个 `UnityEvent`，触发关卡本地绑定。

4. UI 生成与字体链路
   - `UIGenerator` 迁移 PSD/JSON 中的图片透明度和 TMP outline 材质。
   - 生成或引用的新材质、字体资源进入 prefab/UI JSON。
