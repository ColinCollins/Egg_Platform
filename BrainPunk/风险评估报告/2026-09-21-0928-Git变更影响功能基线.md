## B01 RemoteConfig 与 Draw 配置提交

- 缓存流：SDK 回调→解析有效 JSON→保留最近有效值→DB cache→Draw 候选→安全提交→现有 UI 刷新。无效/重复 ID 的 Draw 列表整批拒绝，不部分应用。
- 风险边界：此协调依赖 GuruSDK 回调能代表本轮请求完成；实际 Package 行为见 B02。静态实现不能证明真实 Firebase 节流、晚到回调或 PlayerLoop 暂停时序。
- 回滚：游戏侧需连同回调协调、缓存提交、Draw generation/UI 刷新一起回退，不能只回退单一方法。
