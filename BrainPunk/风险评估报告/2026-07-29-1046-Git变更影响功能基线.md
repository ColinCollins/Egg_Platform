## DrawGame 主流程基线

### 入口与控制器

- `Assets/Game/UI/StartPanel/Scripts/StartPanel.cs` 当前工作区新增 `drawGameBtn`，点击后调用 `GameManager.Instance.TryEnterDraw(out error)`。
- `Assets/Game/Scripts/Play/GameManager.cs` 在启动时创建 `PlayControllerPolicyResolver`、`PlayControllerManager`，注册主线 `PlayCtrl` 与 `DrawPlayCtrl`，并提供 `TryEnterDraw`、`TryEnterDrawLevel`、`ReturnToStartPanel`。
- `Assets/Game/Scripts/Play/PlayControllerManager.cs` 负责玩法切换：解析策略、初始化目标 controller、停用当前 controller、激活目标 controller；异常时尝试停用目标并恢复旧 controller。
- `Assets/Game/Scripts/Play/DrawPlayCtrl.cs` 是 DrawGame 的核心控制器，负责打开 Draw 选关面板、进入 DrawLevel、加载 HUD、异步加载关卡 prefab、驱动关卡运行时、重开、胜利、下一关、返回选关和释放资源。

### UI 链路

- StartPanel 未提交变更把首屏 Draw 入口从原先按名字查找的 `CommonYellowBtn` 变成 Inspector 序列化的 `CustomButton drawGameBtn`，并在 `StartPanel.prefab` 中新增/绑定 `DrawGameEnter` prefab instance。
- DrawGame 选关资源路径为 `Assets/Game/UI/DrawGame/ChoiceLevelPopup/Resources/DrawGame_ChoiceLevelPanel.prefab`，脚本实际位于 `Assets/Game/UI/LevelChoicePanel/Scripts/DrawGame/DrawGame_ChoiceLevelPanel.cs`。
- `DrawGame_ChoiceLevelPanel` 初始化依赖 `ConfigManager.Instance.Tables.TbDrawLevelSort`、`TbDrawLevelData`、`DB.DrawGame`、选关项 prefab 和分页/关闭按钮。关闭按钮通过 `GameManager.Instance.ReturnToStartPanel` 回到首屏。
- `DrawGame_LevelChoiceItem` 根据 `DB.DrawGame.UnlockLevels`、`PassedLevels`、`LevelCollectedStar` 刷新状态。普通/当前/已通过关卡点击进入；广告锁定关卡走 `RewardAdHelper.TryToShowRewardAd`，成功后 `UnlockAndEnter`。
- `DrawGame_GamePlayPanel` 绑定暂停、重开、商店、提示和激励加墨按钮。重开派发 `DrawGameResetEvent`；商店和暂停通过 `GameManager.Instance.ControllerManager.ActivePauseHost` 暂停/恢复；激励加墨走 `RewardAdHelper`，成功后再从当前 active controller 转型为 `DrawPlayCtrl` 并调用 `TryGrantRewardInk`。

### 关卡加载与运行时

- `DrawPlayCtrl` 使用常量资源目录 `Assets/Game/Prefabs/DrawLevel/`，进入关卡时由 `DrawLevelData.Path` 拼出 `_drawLevelPath`，再经 `ResourceManager.Instance.LoadAsync<GameObject>(_drawLevelPath)` 加载 prefab。
- `DrawPlayCtrl` 在加载后创建 `DrawGame_GamePlayPanel`，把 `DrawLevelData.maxInkLength` 和 `inkStarStage1/2/3` 写入 `DrawInkConfig`，再调用 `DrawLevelCtrl.ConfigureInk` 与 `InitializeRuntime`。
- `DrawLevelCtrl` 负责缓存 draw feature、actor、catch、trigger、tips、handler，订阅 Draw 专用触发事件，执行 Tick、ResetAttempt、Pause/Resume、Success/Failed resolve。
- `DrawLineFeature` 按 `isConfig` 决定是否接收外部墨水配置；配置生效时根据 `maxInkLength`、`sampleSpacing`、`stage` 计算墨水长度、星级节点和输入容量。默认 `isConfig=false`。
- `DrawLevelCountdownCtrl` 可接管倒计时，首笔绘制后启动，每帧用 `Time.deltaTime` 推进；倒计时结束按 `isSuccess` 决定成功或失败重开。
- `OnTriggerSuccessCtrl` 优先查找父级 `DrawLevelCtrl` 并调用 Draw 成功 resolve；找不到 Draw 上下文时回退派发主线 `SwitchGameStateEvent`。
- `OnTriggerTrapHandle` 属于主线 Level_27 附近脚本，最近新增触发/碰撞模式切换和延迟失败派发，仍会影响 level 50 以内已上线关卡链路。

## 广告与商业化基线

- `Assets/Game/Scripts/Ads/InterstitialAdPolicy.cs` 新增 `DrawInterstitialAdPolicy`，目标是使用 Draw 独立 RemoteConfig 与 `DB.DrawGame` 广告状态，不读写主线插屏时间、胜败计数或主线弹窗保护状态。
- `DrawPlayCtrl` 作为 `IInterstitialAdPolicyHost` 暴露 Draw 独立插屏策略。失败/重开时调用 `OnPlayerFailedOrRetried` 并尝试 `InterstitialAdHelper.TryToShowInterstitial(InGameFailed)`；胜利时调用 `OnLevelSucceeded` 并尝试 `InGameVictory`。
- `InterstitialAdHelper` 播放前读取 `GameManager.Instance.ControllerManager.ActiveController`，若其实现 `IInterstitialAdPolicyHost` 则使用对应策略；播放成功后调用策略 `OnInterstitialShown`。
- `RewardAdHelper` 播放激励视频前同样捕获 active controller 的插屏策略，激励成功时调用 `policy?.OnRewardAdShown()`。DrawGame 中该接口既被选关广告解锁调用，也被 HUD 激励加墨调用。
- `ConfigManager.RemoteConfig.cs` 和 `GlobalConst`/`lubanconfig_tbglobalconst.json` 提供 DrawGame 插屏 CD、激励重置 CD、最小关卡、间隔关数、失败次数等配置。
