## 1. 主流程与玩法控制器基线

### 原有职责

- `LoadManager` 完成 SDK、DB、配置、UI、资源系统和后处理后，进入 Main 场景。
- `GameManager.ReadyToPlay()` 原先直接持有 `PlayCtrl.Instance` 并初始化主线。
- `GameManager.Update()` 原先直接驱动 `PlayCtrl.Update()`。
- `PlayCtrl` 原先同时负责主线状态机、关卡生命周期、`GamePlayPanel`、暂停/恢复、广告策略、胜负和返回选关。
- `GamePlayPanel` 暂停按钮原先直接派发 `SwitchGameStateEvent(PAUSE)` 并打开 `GameSettingPopup`。
- `GameSettingPopup` 原先退出时走主线 `FAILED` 状态并打开 `ChoiceLevelPanel`。

### 当前工作区变化

- 新增普通对象 `PlayControllerManager`，由 `GameManager.ControllerManager` 持有。
- 新增 `IPlayController`、`IPlayPauseHost`、`IPlayControllerPolicy`、`PlayModeType`、`PlayEntryRequest` 和 `PlayControllerPolicyResolver`。
- `PlayCtrl` 实现 `IPlayController`，事件订阅、Tick、Shutdown 由 Manager 驱动。
- `DrawPlayCtrl` 最小接入 Draw 玩法，当前只加载 `Assets/Game/Prefabs/DrawLevel/DLevel_001.prefab` 并打开 `DrawGame_GamePlayPanel`。
- `StartPanel` 新增 `drawPlay_btn` 入口；`LevelChoiceItem` 把路径 `10999` 识别为 Draw 入口。
- `LoadManager` 调用 `GameManager.ReadyToPlay(out error)`，失败时停止后处理并阻止进入 Main。

### 影响链路

```text
LoadManager.OnPostProcess
  -> GameManager.ReadyToPlay(out error)
  -> PlayControllerManager.Register(Main/Draw)
  -> PlayControllerManager.TryEnter(Main)
  -> PlayCtrl.Initialize/Activate
  -> GameManager.Update -> ControllerManager.Tick
  -> StartPanel.drawPlay_btn 或 LevelChoiceItem path 10999
  -> GameManager.TryEnterDraw
  -> PlayControllerManager.TryEnter(Draw)
  -> PlayCtrl.Deactivate 清主线现场
  -> DrawPlayCtrl.Activate
  -> ResourceManager.LoadAsync(DLevel_001)
  -> DrawGame_GamePlayPanel.Create
  -> GameSettingPopup 通过 IPlayPauseHost 暂停/恢复/返回 StartPanel
```

### 验证基线

- 静态证据确认 `GameManager`、`PlayCtrl`、`LoadManager`、`GamePlayPanel`、`GameSettingPopup`、`StartPanel`、`LevelChoiceItem` 均在未提交 diff 中。
- 当前未见 Unity PlayMode、Android/iOS、实际 Draw 入口点击或加载失败注入证据。
- `DrawPlayCtrl` 有 activation version 门禁和失败回 StartPanel 兜底，但该兜底仍依赖 `GameManager.ReturnToStartPanel` 成功。

## 3. Draw 运行时与选关面板基线

### 收尾复核新增变化

- `Assets/Game/Scripts/Level/DrawLevel/` 新增 `DrawLevelCtrl.cs`、`DrawLevelRuntimeTypes.cs`、`DrawTipsLineRendererNormalizer.cs` 和一份本地功能风险文档。
- `DrawLevelCtrl` 实现 `IDrawLevelRuntime`，由 `DrawPlayCtrl` 在 `DLevel_001.prefab` 实例化后解析并初始化。
- `DrawLevelCtrl.Update()` 处理鼠标/触摸输入，运行时通过 `LineRenderer` 模板实例化画线对象，并通过 `InkChanged`、`StrokeCompleted`、`Resolved` 回调向上游反馈。

- `DrawTipsLineRendererNormalizer` 包含 `OnValidate`，局部文档说明该路径只处理本地 `LineRenderer` 序列化数据，不访问 DB、Save、RemoteConfig 或运行时单例。
