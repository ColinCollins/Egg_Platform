## 本次影响模块基线

### 关卡进入与主状态机

- `PlayCtrl.EnterGame()` 与 `OnEnterNextLevel()` 通过 `EnterLevelLoading.Create(...)` 包装关卡销毁、`CreateLevelAsync(...)`、状态机进入 `PLAYING`。
- `CreateLevelAsync(...)` 负责关闭相机、按 `Assets/Game/Prefabs/Level/{0}.prefab` 加载关卡 prefab、实例化 `BaseLevelCtrl`、刷新 `GamePlayPanel`。
- 最近三天提交 `21595c01b` 将 `CreateLevelAsync()` 中 `await LevelCtrl.TryToPlayEnterDoorAnim()` 改为非等待调用；`BaseLevelCtrl.TryToPlayEnterDoorAnim()` 仍会禁用控制、等待 `EnterDoorAnimCtrl.Play()`、恢复移动与控制。
- 因调用方不等待，门动画、`PLAYING` 状态、公告、免广告弹窗、免费皮肤弹窗、`GamePlayPanel` 输入与 LevelStart 时序存在并发窗口。

### 关卡排序与进度/存档

- `LevelCtrl.Init()` 从 `ConfigManager.Instance.Tables.TbLevelData.DataList` 与 `TbLevelSort.DataList` 初始化关卡数据。
- `LevelCtrl.CurrentLevelData` 通过 `DB.GameData.CurrentLevel` 查找当前 `LevelSort.Id`，再用 `LevelSort.Path` 取 `LevelData`。
- `LevelCtrl.Victory()` 使用 `DB.GameData.CurrentLevel + 1` 推进进度，并以 `levelsort.Last().Id` 判断是否还能进入下一关。
- 当前未提交 `tblevelsort.json` 调整了 id 4-7 对应路径，并将 id 68-74 的路径整体后移并新增 id 74 -> `10087`。该变更会影响前期关卡顺序、后期关卡插入、最后一关判断、解锁/已通关存档映射、公告和免广告弹窗的最后一关判定。
- `LevelCtrl.SyncRemoteConfig()` 也能用远端 `level_sort` 替换本地 `levelsort`，但本次未验证远端配置是否覆盖当前本地排序。

### Level67 降落伞与相机跟随
