## 功能基线一：OneLink 解析、排队与入口门禁

### 变更前

- 基线提交前没有当前这一组 `OneLinkManager`、`OneLinkRequest`、`OneLinkLevelRouter` 生产实现，也没有三玩法统一的深链来源状态和每玩法一次历史。

### 变更后

- `GameSDKService.InitializeAsync()` 在 `GuruSdk.PrepareEnv()` 前初始化 `OneLinkManager`，见 `Assets/Game/Scripts/SDK/Services/Core/GameSDKService.cs:43-48`。
- `GameAnalytics` 将 `OneLinkManager.AppsFlyerHook` 加入 AppsFlyer 转发链，见 `Assets/Game/Scripts/SDK/SDKImps/GameAnalytics.cs:32`。
- `OneLinkManager.HasPendingRequest` 汇总待解析 URL、候选目标和待跳转请求，见 `OneLinkManager.cs:38`；`NotifyHomeOpened()` 与 `TryNavigateFromStartPanel()` 只在首页可见且没有阻塞弹窗时尝试路由，见 `OneLinkManager.cs:192-223,1195-1248`。
- UDL/GCD/Unity `deepLinkActivated`/GM 参数进入同一解析状态机；有效目标最多重试三次，总预算十秒。游戏玩法运行中收到的新请求会被丢弃，返回首页后的新点击才作为新激活处理。
- `TryBeginEntry()` 使用 `DB.GameData.OneinlinkEnterType` 实现每个 `GameType` 每次安装永久自动进入一次；`OnLevelEntryStarted()` 标记运行中来源；只有 `ConfirmLevelEntered()` 才写入历史，见 `OneLinkManager.cs:117-185`。

### UI 与启动弹窗链

- `LoadManager` 依次处理启动弹窗，在 `OneLinkManager.HasPendingRequest` 为真时跳过 ChestGift，最后调用 `NotifyStartupPopupsDispatched()`，见 `Assets/Game/UI/Loading/Scripts/LoadManager.cs:370-443`。
- `StartPanel` 在首页动画和可见性满足后调用 `TryNavigateFromStartPanel()`，见 `Assets/Game/UI/StartPanel/Scripts/StartPanel.cs:115`；`UIManager.HasBlockingPopup()` 为跳转门禁提供弹窗栈、关闭中 UI 与共享遮罩判定。
- 成功从 OneLink 进入关卡后，三类胜利面板隐藏 Replay；普通入口恢复原 Replay 行为。

### 存档与事务链

- 主线路由先调用 `LevelCtrl.UnlockLevel()`；该方法立即写 `DB.GameData.UnlockLevels` 并保存，见 `OneLinkLevelRouter.cs:78` 与 `Assets/Game/Scripts/Play/LevelCtrl.cs:450-456`。
- Draw 路由在开始异步进关前写 `CurrentLevel`、页码、`UnlockLevels` 并调用 `DB.SaveDrawGame()`，见 `DrawGame_ChoiceLevelPanel.cs:482-512`。
- IWanner 路由在开始异步进组前写 `UnlockGroups` 并调用 `DB.SaveIWannerGame()`，见 `OneLinkLevelRouter.cs:221-228`。
- `TryNavigateFromStartPanel()` 在路由调用前清空 `_pending`，见 `OneLinkManager.cs:1231`。同步拒绝会释放当前入口状态，但已经写入的解锁/选择存档没有统一回滚事务。

### 生命周期差异

- Draw 与 IWanner 使用 `_activationVersion` 判断异步回调是否仍属于当前激活，见 `DrawPlayCtrl.cs:59,325,1016` 与 `IWannerPlayCtrl.cs:46,324,1765`。
- 主线 `PlayCtrl.CreateLevelAsync()` 没有请求代次或取消令牌；成功和失败只按 `GameType.Default` 调用 `ConfirmLevelEntered()`/`EndEntry()`，见 `PlayCtrl.cs:675-715,854-856`。
- 因此旧请求 A 退出后、新请求 B 已开始但未完成时，A 的晚到成功/空结果/异常可以修改 B 的 OneLink 运行态或历史。这是隔离抽取生产方法后已复现的 P1 竞态，不是纯假设。
