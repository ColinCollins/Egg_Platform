## 1. DrawGame 主流程控制器基线

### 职责与入口

- `Assets/Game/Scripts/GameManager.cs` 在 `ReadyToPlay(out string error)` 中注册 `MainPlayControllerPolicy`、`DrawPlayControllerPolicy`，并创建/注册 `PlayCtrl` 与 `DrawPlayCtrl`。
- `Assets/Game/UI/Loading/Scripts/LoadManager.cs` 的 `OnPostProcess()` 会调用 `GameManager.Instance.ReadyToPlay(out readyError)`，因此控制器注册失败会扩散到启动后处理。
- `Assets/Game/UI/StartPanel/Scripts/StartPanel.cs` 新增 Draw 入口按钮绑定，点击后调用 `GameManager.Instance.TryEnterDraw(out string error)`。
- `Assets/Game/Scripts/Play/PlayControllerManager.cs` 负责控制器注册、切换、激活、反激活、Tick 与 Shutdown，并向 UI 暴露当前 `IPlayPauseHost`。
- `Assets/Game/Scripts/Play/DrawPlayCtrl.cs` 负责 Draw 玩法选择、异步加载 `Assets/Game/Prefabs/DrawLevel/DLevel_*.prefab`、创建 Draw HUD、监听重置/提示/下一关/重玩事件，以及落盘 `DB.DrawGame`。

### 调用链

```text
LoadManager.OnPostProcess
  -> GameManager.ReadyToPlay
  -> PlayControllerManager.Register(Main/Draw)
  -> StartPanel.TryEnterDraw 或 10999 入口
  -> PlayControllerManager.TryEnter(Draw)
  -> DrawPlayCtrl.Activate / TryEnterLevel
  -> ResourceManager.LoadAsync(DLevel_*)
  -> DrawLevelCtrl.InitializeRuntime
  -> DrawLineFeature / Draw HUD / Draw Victory / Draw Tips / Shop
```

### 依赖

- UI 依赖：`StartPanel`、`DrawGame_GamePlayPanel`、`DrawGame_ChoiceLevelPanel`、`DrawGame_GameTipsPopup`、`DrawGame_GameVictoryPanel`、`ShopPanel`、`ShopRewardTipPopup`。
- 资源依赖：`Assets/Game/Prefabs/DrawLevel`，并依赖 `Assets/BPGame/AssetBundleCollectorSetting.asset` 中新增 DrawLevel 收集规则。
- 配置依赖：`DrawLevelData`、`DrawLevelSort`、`GlobalConst` Draw 广告阈值字段、`ConfigManager.RemoteConfig` Draw getter。
- 存档依赖：`DB.DrawGame.PassedLevels`、`DB.DrawGame.MaxLevel`、`DB.DrawGame.CurrentLevel`、Draw 广告计数与时间戳字段。
- 事件依赖：`DrawGameResetEvent`、`DrawGameHintEvent`、`DrawInkStateChangedEvent`、`GameReplayEvent`、`EnterNextLevelEvent`。
- 广告依赖：`DrawPlayCtrl` 作为 `IInterstitialAdPolicyHost`，通过 `InterstitialAdHelper` / `RewardAdHelper` 进入广告 SDK 回调。
