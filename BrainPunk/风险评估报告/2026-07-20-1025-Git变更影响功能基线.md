## 1. GameTips 首次提示引导基线

### 直接变更入口

- commits：`8420e4cae`、`edcc4cda1`、`1ed7efd47`。
- 主要文件：`GameTipsGuideFlow.cs`、`PlayCtrl.cs`、`PlayCtrl_Playing.cs`、`GamePlayPanel.cs`、`GameTipsPopup.cs`、`GameTipsPopup.prefab`、`NormalGuidePopup` 资源、`GuideDialogue` 资源、`SimpleBag.cs`、`Level_004.prefab`、`GMPanel`。
- 当前未提交文档：`DevelopMD/GameTips_Logic.md` 追加 ClickBlock 基线。

### 当前职责与入口

- `PlayCtrl_Playing.OnUpdate()` 在 Playing 状态复用关卡累计时间和失败/重开次数，首次达到门槛后调用 `owner.TryStartGameTipsGuide(...)`。
- `PlayCtrl` 持有 `GameTipsGuideFlow`，运行前派发 `GamePlayPanelSwitchBlockEvent(true)`，完成/失败/异常后在 `finally` 关闭遮罩。
- `GamePlayPanel` 不持有流程，只提供 `TipsBtn`、Finger 根节点和 `OpenFirstGuideFreeTipsPopup()`；打开提示时沿用既有暂停事件与 `GamePlayPanelSwitchTipsEvent(false)`。
- `GameTipsGuideFlow` 顺序为：NormalGuidePopup 开场 -> Finger 点击 TipsBtn -> 打开首次免费 `GameTipsPopup` -> ClickBlock 开启 -> 免费说明 -> 只开放 YesBtn -> Finger 点击 -> `UseFirstGuideFreeHint()` -> `GameTipsPopup_3` -> 可选收尾对话。
- `GameTipsPopup.SetClickBlocked(bool)` 只解析当前 Popup 根节点下的 `ClickBlock`，不创建对象，不访问全局 UI 层级。

### 依赖与数据链

- RemoteConfig：`gameTipsGuideLevel`、`gameTipsGuideFailedCount`、`gameTipsGuideWaitingTime`，进入 Playing 时读取一次快照。
- DB：`GameData.HasTriggeredGameTipsGuide` 用于一次性触发；`ToolConsumesCache["Tips"]` 作为是否已使用提示的语义记录。
- 事件：复用 `SwitchGameStateEvent`、`GamePlayPanelSwitchTipsEvent`、`GamePlayPanelSwitchBlockEvent`、`UseTipsEvent`；本次未新增 PlayEvents。
- 奖励/成就：首次免费提示通过 `SimpleBag.RecordToolConsume(GameProps.Tips, CostType.Hint)` 记录提示消耗并触发 ToolConsumes 成就检查，不扣金币、不走广告。
- 资源：`GameTipsPopup.prefab` 绑定默认 inactive 的 ClickBlock；`GameTipsPopup_3.prefab` 不承担 Normal 引导 ClickBlock。

### 下次对照重点

- 若继续修改 `PlayCtrl`、`PlayCtrl_Playing`、`GameTipsPopup` 或 `GameTipsGuideFlow`，优先复核：引导状态消费是否过早、暂停/恢复是否配对、ClickBlock 是否在失败和取消路径关闭、免费提示是否重复计数、RemoteConfig 为 0 时是否立即触发。
