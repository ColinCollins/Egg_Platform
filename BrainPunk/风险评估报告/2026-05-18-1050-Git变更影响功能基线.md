## 入口到职责基线

### 1. 首通胜利与奖励面板

- 主入口：`PlayCtrl_Success.OnEnter`
- 当前时序：
  - 先读取 `DB.GameData.LevelSuccessCount` 判断当前关卡是否“曾经通关过”
  - 再执行 `TryToAddSuccessCount()`，同时打关卡成功与插屏成功次数链
  - 先走 `InterstitialAdHelper.TryToShowInterstitial`
  - 再打 `GameSDKService.LevelEndEvent(LevelEndTypeSuccess)`
  - 评分命中时先弹 `RatingPopup`，关闭后再显示胜利面板
  - 首通走 `GameVictoryPanel_Reward`，重复通关走 `GameVictoryPanel`
- 奖励版面板当前组件职责：
  - `GameVictoryPanel`：按钮绑定、Spine 进场、提示文案打字机、Next 按钮状态
  - `HorizontalRandomAdRewardCtrl`：奖励指针左右摆动、停靠、按 RemoteConfig/GlobalConst 刷新奖励倍率文本
  - `CommonUIRewardAnimCtrl`：从奖励起点飞到终点的物品飞行动画
  - `NoAdBtn`：复用 `PurchaseManager` 购买 `ProductName.NoAds`
- 关键依赖：
  - 下一关：`EnterNextLevelEvent -> PlayCtrl.OnEnterNextLevel -> EnterLevelLoading -> CreateLevelAsync`
  - 评分：`RatingPopupPolicy.TryToShowRating`
  - 成就：`WaitingUnlockAchievement -> GameAchievementUtils.TryToAchievement/LoadAchievementCacheAsync`
  - 购买：`Products.GetProductId -> PurchaseManager.Purchase -> PurchaseManager.OnPurchaseSuccess`

### 2. GuideBubble / HintBubble

- 主入口：`PlayCtrl_Playing.UpdateGuideBubble`
- 当前时序：
  - 每帧读取 `Level.CurrentLevelData.HintsTime` 与 `HintsDesc`
  - 达到触发时间后，通过 `LevelRuntimeState.HasShownGuideBubble` 防止同一次尝试重复派发
  - `BaseLevelCtrl` 收到 `ShowHintBubbleEvent` 后动态实例化 `Resources/HintBubble`
  - `HintBubble.Show` 现在读取 `HintsDisappearTime` 控制自动关闭时间
  - `HintBubble` 订阅 `SwitchLanguageEvent`，当语言切换时刷新当前文案
- 当前状态基线：
  - `LevelRuntimeState.ResetStateData/StartLevel` 会重置 `HasShownGuideBubble`
  - `HintBubble` 销毁条件来自 actor 丢失、关闭动画完成或定时关闭

### 3. 多语言与字体链

- 最近三天 commit 已将 `es-ES` 与 `es-US` 语言列分开，并填充了一批 `es-US` 词条
- 当前运行链：
  - 文案取值：`LocalizationManager.GetTranslation(key)`
  - 展示路径：`HintBubble.RefreshTips`、`GameVictoryPanel.RefreshTips`、Loading/Shop/Rate 等 UI
  - 字体链：最终依赖 TMP Font Asset atlas 是否可用，尤其是 `en SDF`、`korean SDF`、`Twinkly SDF`
- 当前工作区又打开了 GF 子模块里的 `DOTweenTextMeshPro` 支持，使 `DOText/DOFade/DOColor` 走到 TMP 扩展代码

### 4. 当前工作区调试配置链

- `ProjectSettings.asset` 当前把 `DEBUG_MODE` 加入了 Android、Standalone、WebGL、iPhone
- 这些 define 会直接改变以下入口：

  - `GameSettingPopup.OnGUI`：绘制调试信息
  - `DebugModeSwitchAllBtns`：把所有调试按钮判定为可用
  - `Booster.Init`：真机启用 `reporter`
