## 功能职责与调用链基线

### 平台和构建配置

- `QualitySettings.asset` 是 Unity 平台默认质量档配置。Android/iPhone 默认质量映射清空会扩散到移动端启动默认质量选择、URP/纹理/阴影/粒子预算和横屏性能表现。
- `PackageManagerSettings.asset`、`guru_gf_settings.txt`、`build_info` 当前更像编辑器/环境状态，不应和业务风险修复混入同一提交，除非明确要更新环境基线。

### CommonGetRewardPopup 奖励弹窗

- `CommonGetRewardPopup.Create(...)` 打开 `UILayer.Popup` 后调用 `SetData(...)`，`SetData(...)` 会立即执行 `GrantNormalReward()`。
- Coin/Star 通过 `PlayCtrl.Instance?.Bag.AddTool(...)` 写入；Skin 通过 `Bag.GetNewSkin(...)` 写入。
- 广告按钮调用 `RewardAdHelper.TryToShowRewardAd(RewardPlacement.ShopCloseReward.ToString(), ...)`，成功后 `GrantAdReward()` 只追加 Coin/Star 的 `multiple - 1` 倍，不追加 Skin。
- 关闭时如果含 Coin，会等待 `CommonUIRewardAnimCtrl.PlayFrom(...)`，最后 `prop.UpdateData()` 并销毁 UI。
- `BaseParamUtils` 负责把 Luban `ParamBase`、基础数值或字符串转换为奖励数量 / Skin id。

### Skin 资源加载

- `SkinUtils.ResolveIconLocation(skin)` 仅在 `TextureResources` 为短名时拼接 `Assets/Game/ArtSrc/Skins/UI/{TextureResources}.png`，并通过 `ResourceManager.CanLoad<Sprite>()` 校验。
- `SkinUtils.ResolvePrefabLocation(prefabResource)` 在短名时拼接 `Assets/Game/Prefabs/Skins/{PrefabResource}.prefab`。
- `GetSkinPopup`、`SkinItem`、`CommonGetRewardPopup` 依赖 `ResolveIconLocation` 显示皮肤图标；`ActorSkinBinding` 和 `ShopPanel_SkinPart` 依赖 `ResolvePrefabLocation` 加载实际部件 prefab。
- 本次新增 Skin 条目的 prefab 存在，但同名 UI 图标缺失，因此运行时可能能穿戴/预览部件，但商店、奖励弹窗、获取弹窗图标为空。

### 明信片胜利星与选关星组

- `PlayCtrl_Success.ShowVictory(isFirstVictory)` 首次通关前置发放默认胜利星，`PostcardManager.TryGrantVictoryStars(...)` 写入 `LevelCollectedStar` 和 `LevelWaitingAnimStar`。
- `GameVictoryPanel.Create(data, hasReward)` 调用 `RefreshPostcardVictoryStars(data)`，优先刷新 `Postcard_VictoryStarGroupCtrl`；缺失组件时兜底消费 `LevelWaitingAnimStar`。
- `Postcard_VictoryStarGroupCtrl.Refresh(levelData)` 只在 PlayMode 执行，会消费等待动画数量并刷新 Toggle，动画依赖 DOTween / UniTask。
- `Postcard_ChoiceLevelStarGroupCtrl.Refresh(...)` 只读 `PostcardManager.GetLevelCollectedStarIds(levelId)`，不写入存档，也不消费等待动画计数。

### 明信片弹窗与宝箱

- `PostcardPopup.Create()` 固定打开 `PostcardPopup` 到 `UILayer.Popup`。
- 当前未提交 prefab 把 `Postcard_Chest` 挂到 `PostcardPopup.prefab`，并实例化 `Postcard_ChestPreviewBubble`。
