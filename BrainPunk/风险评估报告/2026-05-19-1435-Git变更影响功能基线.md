## 入口到职责基线

### 1. 首通 Victory 奖励闭环

- 主入口：`PlayCtrl_Success.OnEnter()`
- 当前时序：
  - 先读取当前关卡是否已有成功记录，再决定是否进入奖励版 Victory。
  - 关卡成功后先尝试插屏，再打 `LevelEndEvent(LevelEndTypeSuccess)`。
  - 首通走 `GameVictoryPanel_Reward`，广告成功回调后执行 `PlayRewardFlowAsync()`。
  - 奖励流当前会执行 `adRewardCtrl.Stop()`、`GrantRewardCoins()`、`rewardAnimCtrl.Play()`，最后自动派发下一关事件。
- 当前保护：
  - `GameVictoryPanel` 已加入 `_isNextLevelTriggered` 防止重复进下一关。
  - `HorizontalRandomAdRewardCtrl` 当前会用 `HasValidRewardTextBindings()` 校验文案引用。

### 2. Schedule / Daily 调度

- 主入口：`LoadManager.EnterGame()`
- 当前时序：
  - `DBManager.Initialize()` 之后立即注册 `DailyScheduleModule`。
  - `ScheduleSystem.CheckAllModules()` 只遍历启动时已经注册进来的模块。
  - `GameSchedule` 当前保存三类状态：`scheduleLastRefreshTimes`、`daily_interstitialNoAdPopupShowCount`、`daily_shopFreeCoinShowCount`。
- 当前约束：
  - `ScheduleModuleBase.CheckAndRefresh()` 只在 `ShouldRefresh()` 命中时执行。
  - 每个 `IScheduleRefreshable` 的异常都被 `try/catch` 包住，不阻断其他模块。

### 3. 插屏后 NoAds 自动弹窗

- 主入口：`InterstitialAdHelper.InternalCallback(success)`
- 当前时序：
  - 插屏成功后先重置 Interstitial 计数，再调用 `ShouldShowNoAdPopup()`。
  - 命中次数阈值后直接 `NoAdsPopup.Create()`，随后 `RecordShow()` 增加当日计数。
  - `NoAdsPopup.Create()` 默认把 `lastUIName` 设为 `ChoiceLevelPanel`，并立刻打 `IAP_IMP`。
- 当前依赖：
  - 展示次数上限：`ConfigManager.RemoteConfig.GetAdDailyNOAdPopupAutoShowCount()`
  - 展示次数持久化：`DB.GameSchedule.Daily_interstitialNoAdPopupShowCount`
  - 商店打点：`GameSDKService.IAP_IMP / IAP_CLOSE / IAP_CLK`

### 4. ShopPanel 页面改版

- 主入口：`ShopPanel.Create()`
- 当前时序：
  - `ShopPanel.Generated.cs` 负责新版预制体字段注入。
  - `ShopPanel.cs` 仍按 4 个固定商品位映射 `NoAds / Hint1 / Hint2 / Hint99`。
  - 购买成功后继续走 `PurchaseManager.OnPurchaseSuccess()`，再刷新 sold-out 状态。
- 当前状态：
  - `daily_shopFreeCoinShowCount` 只落在 `GameSchedule`，尚未被 `ShopPanel.cs` 或其他脚本消费。

### 5. GameTipsPopup 价格与通关提示

- 主入口：`GameTipsPopup.RefreshTips() / TryToPassLevel() / TryToUseCoins()`
- 当前变化：
  - PassLevel 分支改成读 `GetGameTipsPopupPassLevelCoinCost()`。
  - 普通提示仍读 `GetGameTipsPopupCoinCost()`。
  - 远端 `level_config` 现在至少包含 `victoryHorziontalRewards` 与 `gameTipsPopupCoinCost`，PassLevel 价格默认依赖本地 `GlobalConst` 兜底。

### 6. 当前工作区调试入口与 GM 面板

- 主入口：`StartPanel.OnCreate()`
- 当前时序：
  - `ProjectSettings.asset` 里 Android、Standalone、WebGL、iPhone 目前都带 `DEBUG_MODE`。
  - `StartPanel.OnCreate()` 在 `#if DEBUG_MODE` 下直接 `GMPanel.Create()`。
  - `GMPanel.prefab` 本地已改成带 `ScrollRect + Mask + PageView` 的分页布局。
  - `PageView.cs/.meta` 当前还是未跟踪文件，说明 prefab 和脚本依赖还没有一起进入版本控制。

### 7. 当前工作区字体与 GF TMP 扩展

- 主入口：GF 子模块 `DOTweenPro` 编译路径与各 UI 的 TMP 文本组件
- 当前变化：
  - `DOTweenPro.Scripts.asmdef`、`DOTweenPro.EditorScripts.asmdef` 新增 `Unity.TextMeshPro` 引用。
  - `DOTweenAnimation.cs`、`DOTweenAnimationInspector.cs`、`DOTweenTextMeshPro.cs` 把 `TEXTMESHPRO_MARKER / MODULE_MARKER` 从 `false` 改成 `true`。
  - `korean SDF.asset` 当前 atlas 宽高从 `1024x1024` 退化到 `1x1`；`en/Twinkly` 也有大体量二进制重写。

## 已确认的近期行为变化

- Victory 奖励链已从“只做表现动画”变成“广告成功后实际发金币并自动进下一关”。
- GameTipsPopup 的 PassLevel 价格现在已经真正走独立配置项，不再复用普通提示价格。
- Schedule 系统已经从单一 DailyRefresh 文档迁移为 `DevelopMD/Schedule/` 目录下的模块化文档。
