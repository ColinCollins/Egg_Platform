## 入口到职责基线

### 1. 调试入口直连启动链

- 主入口：`StartPanel.OnCreate()`
- 当前时序：
  - `ProjectSettings.asset` 当前把 `DEBUG_MODE` 打进 `Android / Standalone / WebGL / iPhone`。
  - `StartPanel.OnCreate()` 在 `#if DEBUG_MODE` 下直接执行 `GMPanel.Create()`。
  - `GMPanel.OnCreate()` 会调用 `ResolvePagesReference()`，在运行时自动查找 `PageView`。
  - `GMPanel` 打开后可继续触发广告调试、关卡跳转、解锁、清档和 Schedule 调试按钮。

### 2. GF TMP 扩展与字体渲染链

- 主入口：GF 子模块 `DOTweenPro` 的 TMP 编译分支
- 当前状态：
  - `DOTweenPro.Scripts.asmdef` 和 `DOTweenPro.EditorScripts.asmdef` 新增了 `Unity.TextMeshPro` 引用。
  - `DOTweenAnimation.cs`、`DOTweenAnimationInspector.cs`、`DOTweenTextMeshPro.cs` 把 `TEXTMESHPRO_MARKER / MODULE_MARKER` 从 `false` 切到 `true`。
  - 当前工作区里 `Twinkly SDF.asset`、`korean SDF.asset` 的 `Texture2D.m_Width/m_Height` 已变成 `1x1`，`en SDF.asset` 也被大体量重写。

### 3. ShopPanel 自动奖励提示链

- 主入口：`ShopPanel.OnClose()`
- 当前时序：
  - `ShopPanel.OnCreate()` 中创建 `ShopAdRewardTipAutoShowModule`，它会向 `DailyScheduleModule` 注册自己。
  - 关闭商店时先调用 `ShouldShowRewardTip()`，命中后执行 `ShopRewardTipPopup.Create("20000")` 并 `RecordShow()`。
  - `ShopRewardTipPopup` 通过 `shopId` 查 `TbShop` 奖励，广告成功后给 `PlayCtrl.Instance.Bag` 发奖并播放飞行动画。
- 当前约束：
  - 展示次数上限来自 `RemoteConfig.GetShopFreeCoinShowCount()`。
  - 每日计数保存于 `DB.GameSchedule.Daily_shopFreeCoinShowCount`。

### 4. 插屏后 NoAds 自动弹窗链

- 主入口：`InterstitialAdHelper.TryToShowInterstitial()`
- 当前时序：
  - `InterstitialAdHelper` 的静态字段在首次使用时创建 `InterstitialNOAdPopupAutoShowModule`。
  - 插屏成功回调里会调用 `ShouldShowNoAdPopup()`，命中后直接 `NoAdsPopup.Create()`，随后 `RecordShow()`。
  - `NoAdsPopup.Show()` 和 `ClosePopup()` 分别打 `IAP_IMP/IAP_CLOSE`。
- 当前约束：
  - 展示次数上限来自 `RemoteConfig.GetAdDailyNOAdPopupAutoShowCount()`。
  - 每日计数保存于 `DB.GameSchedule.Daily_interstitialNoAdPopupShowCount`。

### 5. Victory 首通奖励闭环

- 主入口：`GameVictoryPanel.PlayRewardFlowAsync()`
- 当前状态：
  - 奖励广告成功后执行 `GrantRewardCoins()`，并通过 `rewardAnimCtrl.Play()` 播放收集动画。
  - 奖励动画完成后 `propBlock.UpdateData()` 刷新货币显示，并自动派发 `EnterNextLevelEvent`。
  - `_isNextLevelTriggered` 已用于防止重复派发下一关。

### 6. GameTipsPopup 提示/通关成本链

- 主入口：`GameTipsPopup.RefreshTips()`、`PassLevelByCostCoin()`、`TryToUseCoins()`
- 当前状态：
  - `PassLevel` 分支已明确读取 `GetGameTipsPopupPassLevelCoinCost()`。
  - 普通提示仍使用 `GetGameTipsPopupCoinCost()`。
  - 缺币分支继续跳转到 `ShopPanel.Create()`，因此 ShopPanel 新改动会直接反馈到提示系统。

### 7. 新关卡 prefab 增量

- 主入口：`LevelCtrl` 通过 `TbLevelSort` 与 prefab 名称映射进入关卡。
- 当前状态：
  - 最近三天新增了 `Level_060/061/062/064/065.prefab` 及配套图片。
  - 本轮没有看到新的 `LevelCtrl` 或 `TbLevelSort` 运行时代码改动，因此当前判断更偏向“内容增量”，需要玩法回归验证。
