## 本次受影响职责

### 明信片弹窗与解锁

- `Assets/Game/UI/Postcard/Scripts/PostcardPopup.cs` 负责读取 `TbPostcardConfig`、加载 `Resources` 下的明信片页 prefab、维护当前页索引、刷新标题和宝箱、在页面 `OnShow()` 后尝试启动 pending guide。
- `PostcardPopup.TryStartPendingPostcardGuide()` 只在 `Application.isPlaying` 下运行；当 `DB.Postcard.IsGuiding` 为 true 时，解析 `Postcard_GuidePart` 并调用 `TryStartGuide()`，随后调用 `ConsumePendingGuideState()` 把 `IsGuiding` 写回 false。
- `Postcard_PageItem.TryUnlockItem()` 是解锁权威入口：检查 `DB.Postcard`、当前星星数、已收集 puzzle、写入 `CurrentCollectedPuzzledId` / `CompletedId`，`DB.SavePostcard()` 成功后再调用 `PlayCtrl.Instance.Bag.RemoveTool(GameProps.Star, unlockCount, CostType.Other)`。
- `Postcard_ProgressItem.PlayUnlockAnim()` 只负责 UI 表现：隐藏红点和消耗块、激活 cover、播放 `Postcard_TurnEffect.TryClosePage()`，失败时直接完成回调避免卡住。

### 明信片指引

- `PostcardGuidePopup.Create()` 打开 guide popup 并记录 `HasGuide=true, IsGuiding=true`；`OnClose()` 记录 `HasGuide=true, IsGuiding=false`。
- `Postcard_GuidePart` 只做局部遮罩、目标按钮、finger 定位和引导推进。真实扣星、存档、完成状态仍交给 `Postcard_PageItem.TryUnlockGuidedItemByListIndex()`。
- 指引目标以 guide 层 `Postcard_ProgressItem` 列表下标对应真实页 `_runtimeItems` 下标。若 prefab 列表顺序或数量不一致，`IsValidTargetPair()` 会跳过目标，但 pending guide state 仍可能被消费。

### 明信片星星收集与 HUD 表现

- `Postcard_Star.Collect()` 在关卡内触发：确认当前关卡 key、避免重复收集、写入明信片星星记录、发放 `GameProps.Star`，再派发 `PostcardGetStarEvent`。
- `GamePlayPanel` 在 `OnOpen()` 订阅 `PostcardGetStarEvent`；`GamePlayPanel.PostcardStar` 根据场景世界坐标创建 UI 飞星并飞到 `PropBlock`，完成后刷新 HUD 星星块。
- `PropBlock.PlayRewardFeedback()` 从 `PlayCtrl.Instance.Bag` 读取实际数量，按最近一次 `UpdatePropEvent` 计算浮动增量。
