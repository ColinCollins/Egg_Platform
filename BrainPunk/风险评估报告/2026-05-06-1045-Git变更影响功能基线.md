## AppsFlyer 初始化与归因链路

### 职责

- `Assets/Game/Scenes/Loading.unity` 是首场景，包含 `GameManager`、`Booster`、`LoadManager`、`UIManager` 和本次新增的 `Appsflyer` 根节点。
- 新增根节点挂载 `Packages/com.guru.sdk.framework.analytics.appsflyer/Runtime/GuruAppsflyerManager.cs`，负责接收 AppsFlyer conversion data、deep link attribution 回调，并通过 `BehaviorSubject` 暴露给 `GuruAppsflyer`。
- `Assets/Game/Scripts/SDK/SDKImps/GameAnalytics.cs` 通过 `GuruAppsflyer.Prepare(CreateAppsFlyerConfig())` 注册 AppsFlyer 自定义 transmitter，显式允许 IAP、订阅、留存和部分关卡完成事件进入 AppsFlyer。

### 启动链路

`Loading.unity` 场景加载 -> `LoadManager.Awake()` 组装启动队列 -> `LoadManager.EnterGame()` 调用 `Booster.Init()` -> `Booster.Init()` 调用 `GameSDKService.Instance.InitService().Forget()` -> `GameSDKService.InitService()` 执行 `GuruSdk.PrepareEnv()`、`PrepareManger()`、`GuruSdk.Initialize(new GameProtocol())` -> `GameProtocol.AnalyticsDelegate` 返回 `GameAnalytics.Instance` -> `GameAnalytics` 创建 `GuruAppsflyer` transmitter -> `GuruAppsflyer.Prepare()` 调用 `InitAppsFlyerMonoBehaviour()`，若场景已有 `GuruAppsflyerManager.Instance` 则不再动态创建。

### 回调/持久化/打点链路

AppsFlyer SDK -> `GuruAppsflyerManager.onConversionDataSuccess()` -> `ObservableConversionData` -> `GuruAppsflyer.CheckAndListenAppsflyerConversionData()` -> `ProcessAppsflyerConversionDataChanged()` -> `GuruAnalytics.SetUserProperty("af_media_source"/"af_campaign")` 与 `AppProperty.Instance.SetAppsflyerConversionData()`。

AppsFlyer transmitter -> `GuruAppsflyer.Transmit()` -> `AppsFlyer.sendEvent()`，事件来源包括 `PlayCtrl`/`PlayCtrl_Success`/`PlayCtrl_Failed` 的关卡开始结束打点、`SimpleBag` 的虚拟货币变化、`PurchaseManager` 的 IAP/恢复购买流程、广告收入链路 `TransmitAdRevenue()`。

### 本次变化影响

- 场景预挂 `GuruAppsflyerManager` 会让 conversion/deep link 回调接收者在 SDK `Prepare()` 之前存在，理论上降低动态创建晚一帧带来的回调错过风险。
- 同时它把 SDK 回调接收对象变成首场景持久化对象，影响打点、广告收入、IAP 收入归因和首次安装归因持久化。

## TMP 字体与本地化 UI 链路

### 职责

- `Assets/Game/ArtSrc/Font/en SDF.asset` 是主 UI/关卡 TMP 字体，GUID `12f68b3f2983cc441b88f268e04f9783`，被 StartPanel、LoadingPanel、GamePlayPanel、GameVictoryPanel、ShopPanel、SettingPopup、CommonPopup、GameTipsPopup、多个关卡 prefab 直接引用。
- `Assets/Game/ArtSrc/Font/Twinkly SDF.asset` 是装饰/标题类 TMP 字体，GUID `efb3a264e009e1f4784c9b314a3bb8f2`，被 GameVictoryPanel、Tips、NoAdsPopup、Level 26/31/35/51/54/58 等引用。
- `Assets/Game/ArtSrc/Font/korean SDF.asset` 是 `en SDF` 和 `Twinkly SDF` 的 fallback，GUID `57abaa08731e8754cb5a8085bfa2bce7`。

### 调用/资源链路

Prefab TMP_Text.fontAsset -> TMP 字体资产 -> glyph/character table、atlas texture、fallback table -> I2 Localization 文本刷新 -> `TextMeshProUGUI.UpdateFontAsset()`、`ForceMeshUpdate()`、`DOText()` 等运行时文字显示。

典型入口：

- `LoadManager` loading 文案通过 `LocalizationManager.GetTranslation()` 写入 TMP 文本。
- `StartPanel` 由 `PlayCtrl` 打开并引用 `en SDF`。
- `GameVictoryPanel.RefreshTips()` 获取本地化文案后调用 `TipsTxt.UpdateFontAsset()`、`ForceMeshUpdate()`、`TipsTxt.DOText()`。
- `SystemTips.Show()` 和 `ShopItem`、`PurchaseManager` 等 UI 文案依赖相同字体链路。

### 本次变化影响

- 三份字体资产的 atlas texture 从 1024x1024 改为 1x1，`m_GlyphTable` 与 `m_CharacterTable` 被清空，`m_UsedGlyphRects` 被清空，保留动态 atlas 配置和 fallback。
- 该变化会把已有静态字形缓存改为运行时动态生成路径，影响首屏、关卡内文字、商店/IAP 文案、设置语言弹窗、胜利面板逐字动画等 UI 流程。
