- `BaseLevelCtrl.PlaySuccessAnim()` 当前在存在 `successAnim` 时先启动 `TryToCollectStar(successAnim.transform.position, 2.5f)`，等待成功动画回调后 `ContinueSuccessAfterCollect()`。
- `TryToCollectStar()` 只在运行态、当前关卡允许收集、关卡 id 有效、`GameManager.Instance.Postcard` 可用且第 3 颗星未收集时继续。

- 影响链路：关卡成功动画 -> `BaseLevelCtrl.TryToCollectStar()` -> `PostcardManager.TryCollectLevelStar()` -> `DB.SavePostcard()` -> 背包 Star -> `PostcardGetStarEvent` -> `GamePlayPanel.PostcardStar` HUD 飞星 -> `SwitchGameStateEvent.SUCCESS` -> `PlayCtrl_Success`。

### 2.2 首次通关胜利星补齐

- `PlayCtrl_Success.ShowVictory()` 在 `isFirstVictory` 时调用 `TryToGetPostcardVictoryStar()`，随后创建 `GameVictoryPanel` 并执行 `owner.Level.Victory()`。
- `TryToGetPostcardVictoryStar()` 通过 `PostcardManager.TryGrantVictoryStars(levelData.Id, levelData.LevelVictoryStarCount)` 写入首次通关默认星。
- `PostcardManager.TryGrantVictoryStars()` 以 3 -> 1 的 star id 递减写入，已有 id 不重复，保存失败会回滚新增的 `LevelCollectedStar` 与 `LevelWaitingAnimStar`。
- 影响链路：首次通关 -> `TryGrantVictoryStars()` -> `DB.Postcard.LevelCollectedStar` / `LevelWaitingAnimStar` -> `GameVictoryPanel.RefreshPostcardVictoryStars()` -> `Postcard_VictoryStarGroupCtrl` 动画展示 -> `ConsumeCollectedStarCount()` 清理等待动画计数。

### 2.3 启动后历史通关星补齐

- commit `79a703644 PostcardPopup 获取星星逻辑调整` 在 `LoadManager` 启动流程加入 `GameManager.Instance?.Postcard.TryGetAllCompleteLevelStar()`。
- `TryGetAllCompleteLevelStar()` 遍历 `DB.GameData.PassedLevels`，通过 `LevelCtrl.GetLevelSortById()` 和 `GetLevelDataById()` 解析关卡配置，再调用 `TryGrantVictoryStars()`。
