## 功能职责与调用链基线

### RemoteConfig / 启动配置

- 入口：`LoadManager.LoadConfigAsync()` 调用 `RemoteConfigService.TryToClearRemoteCache()`，再调用 `RemoteConfigService.UpdateRemoteConfigsForLoadManager()`，随后执行 `ConfigManager.Instance.InitializeAsync(...)`。
- 数据链：`RemoteConfigService` 从 `RemoteConfigManager.Instance.ForceFetch()` 获取远端值；失败时回退到 `DB.GameData.RemoteConfigCache`，再回退到 `GuruSdk.Instance.RemoteConfigSpec.DefaultValues`。
- 持久化链：`ConfigManager.RemoteConfig.SetRaw()` 写入 `DB.GameData.RemoteConfigCache` 并保存；`ClearRemoteCache()` 清本地缓存并更新 `CurrentAppVersion`。
- 影响标签：游戏主线核心流程、远端配置、DB/存档、SDK 初始化。

### LevelSort / 关卡加载

- 入口：`LevelCtrl.Initialize()` 先读取本地 `TbLevelSort.DataList`。
- Remote 覆盖链：`LevelCtrl` 后续通过 `ConfigManager.RemoteConfig.TryGetValue(LevelConfigKey, LevelSortKey, ...)` 解析 `level_sort`，解析成功后用 `_cacheLevelSort` 替换本地 `levelsort`。
- 资源链：`levelsort.path -> tbleveldata.id -> LevelData.path -> Level_0xx prefab`。
- 本次差异：本地新增 10061-10068，但 Guru 默认 remote `level_sort` 新增的是 10058/10055/10057/10056，可能导致包内默认 fallback 与本地新增关卡顺序不一致。
- 影响标签：游戏主线核心流程、资源加载、RemoteConfig。

### 胜利结算 / 分享 / 反应打点

- 入口：`GameVictoryPanel` / `GameVictoryPanel_Reawrd` / `GameVictoryPanel_Share`。
- 奖励链：分享按钮领取 `ConfigManager.RemoteConfig.GetLevelVictoryShareCoinReward()` 金币，经 `PlayCtrl.Instance.Bag.AddTool(... RewardType.Media)` 落入背包。
- 打点链：点赞/点踩调用 `GameSDKService.Instance.LevelVictoryReaction(levelPath, isLike)` 上报 `level_name` 与 `isLike`。
- 状态链：奖励面板被 ShopPanel 等 UI 遮盖时走 `OnHide -> OnShow`，本次通过 `hasHide` 重新显示分享/点赞区域。
- 影响标签：界面弹窗、打点数据统计模块、奖励路径。
