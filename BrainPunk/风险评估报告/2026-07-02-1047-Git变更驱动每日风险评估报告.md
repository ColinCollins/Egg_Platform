## 变更入口到影响链路

### Postcard 星星与存档链路

`Postcard_Star.cs` 会在收集成功后写入 `DB.Postcard.LevelVictoryStar`，`DB.SavePostcard()` 成功后再调用 `PlayCtrl.Instance.Bag.AddTool(GameProps.Star, 1, RewardType.Other)`，随后派发 `PostcardGetStarEvent`。`PostcardManager` 订阅该事件并按当前关卡 id 累加 `DB.Postcard.LevelCollectedStar`，胜利面板创建时通过 `GameManager.Instance.Postcard.ConsumeCollectedStarCount(levelId)` 一次性读取并清空。  
扩散链路：关卡 prefab 星星实例 -> 触发器/碰撞 -> `Postcard_Star` -> DB 永久收集记录 -> 背包奖励 -> 事件 -> 临时胜利计数 -> `GameVictoryPanel` 展示。  
影响模块标签：DB/存档、奖励、胜利 UI、已发布关卡内容、游戏主线核心流程。

### Postcard 活动入口与 RemoteConfig

`PostcardEnter.OnEnable()` 在运行时读取 `ConfigManager.RemoteConfig.IsOpenPostcard()`；该方法优先读取 `level_config.isOpenPostcard`，失败时回退到 `GlobalConst.IsOpenPostcard`。`fa63a22c5` 同步改动了 Luban 生成代码、本地 JSON、Guru spec 与 generated spec。  
扩散链路：`PostcardEnter.prefab` / `ChoiceLevelPanel.prefab` 或 `StartPanel.prefab` 入口 -> RemoteConfig cache -> GlobalConst fallback -> `gameObject.SetActive(false)` 或打开 `PostcardPopup`。  
影响模块标签：RemoteConfig、活动入口 UI、资源/prefab、平台配置基线。

### PlayCtrl 重玩与胜利面板

`GameVictoryPanel.ReplayCurrentLevel()` 销毁自身并派发 `GameReplayEvent`；`PlayCtrl.OnGameReplayEvent()` 读取 runtime level id，校验 `LevelSort` 与 `LevelData`，设置当前关卡，记录 `GameSDKService.LevelStartEvent(LevelStartTypeReplay)`，再重建关卡。普通 reset 仍由 `GameResetEvent` 上报 failed end、replay start 和插屏。  
扩散链路：胜利面板按钮 -> 全局事件 -> `PlayCtrl` 状态与关卡重建 -> SDK 打点 -> gameplay panel fade in -> 当前关卡重新进入。  
影响模块标签：游戏主线核心流程、打点数据统计、UI 弹窗、广告插屏差异。

### 胜利奖励广告
