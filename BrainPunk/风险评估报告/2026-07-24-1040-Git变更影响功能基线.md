## 二、DailyChallenge 基线

- 成功入口：`PlayCtrl_Success.OnEnter()` 进入 SUCCESS 状态后，先调用 `DailyChallengeManager.TryUnlock(currentLevel)`，随后异步结算路径调用 `TryRecordVictory(...)`。
- 解锁状态：`GameData` 新增 `hasUnlockDailyChallenge`，`GameData_Partial` 暴露 `HasUnlockDailyChallenge`。缺字段旧存档默认 `false`，达到 `dailyChallengeUnlockLevel` 的成功关卡保存后永久为 `true`。
- 初见广告保护：`InterstitialAdPolicy.CanShowInterstitial(...)` 在胜利广告位读取 `DailyChallengeIsOpen`、`HasShowDailyChallenge`、解锁关卡与 `PassedLevels`，用于第一次有效 DailyChallenge 展示前跳过胜利插屏。
- 奖励倍率：`ConfigManager.RemoteConfig.GetDailyChallengeRewardMultiple()` 读取 `level_config.dailyChallengeRewardMultiple`，回退 `GlobalConst.DailyChallengeRewardMultiple`，最后回退 `2`，小于 1 的值按 1 处理。
- 奖励领取：`DailyChallengePopup.SetData(...)` 打开时让 Manager 对待领取阶段执行 `TryClaimRewardOnPopupOpen(...)`，同步发放 normal Coin/Star/Skin 并保存 `DailyChallengeHasRewardId`，随后 `CommonGetRewardPopup` 只展示 normal 奖励并继续广告额外奖励。
- UI 显示：`DailyChallengePopup` 和 `CommonGetRewardPopup` 通过 `remainingHiddenCoinAfterReward` 隐藏尚未展示的前置 Coin，避免双阶段奖励提前显示最终余额。

## 三、CommonGetRewardPopup / SimpleBag 基线

- `SimpleBag.GrantRewards(...)` 只接收已解析为 `int` 的 Coin/Star 数量奖励和倍率，内部复用 `AddTool(...)` 的保存、事件与打点链路。
- `CommonGetRewardPopup.Create(...)` 新增 `grantNormalReward`，默认 `true` 保持旧行为；传 `false` 时只展示 normal 奖励，不重复写入普通奖励。
- `CommonGetRewardPopup.Create(...)` 新增 `remainingHiddenCoinAfterReward`，仅在 `grantNormalReward:false` 时控制弹窗内 Coin 显示基线；广告额外 Coin 仍由弹窗写入。
- `PropBlock.UpdateData(int)` 只更新 UI 显示目标，不读写背包；无参 `UpdateData()` 仍读取真实 Bag。

## 四、Postcard 页面完成奖励基线

- `Postcard_PageItem.TryUnlockItem(...)` 在 `DB.SavePostcard()` 成功、扣除星星后，如果当前页刚完成，调用 `_owner.TryGrantPageCompleteNormalRewards(config)`。
- `PostcardPopup_PageCompleteProcess.HandlePageCompleteAsync(...)` 在首个异步等待前再次调用同一入口作为兜底。
- `TryGrantPageCompleteNormalRewards(...)` 解析 `PostcardConfig.Rewards` 中的 Coin、Star、Skin，复用 `SimpleBag.GrantRewards(...)` 与 `GetNewSkin(...)`；同一 Popup 生命周期用 `_grantedPageCompleteRewardIds` 防止同页重复发放。
- 完成奖励弹窗随后以 `grantNormalReward:false` 展示已发放 normal 奖励；前置发奖失败时回退为弹窗默认发奖。
- 风险边界：Postcard 完成存档、星星扣除和 GameData 奖励保存不是事务；本地 HashSet 只保护当前 Popup 生命周期，不是持久领取标记。
