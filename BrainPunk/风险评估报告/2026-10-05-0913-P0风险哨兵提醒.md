- **问题**：`mainTemplate.gradle` 的实际 Gradle 依赖改为 FusionAds 1.5.2，AAR 内容相较 1.5.1 确有变化；静态版本声明一致，但没有本轮清洁构建和真机初始化、加载、展示、关闭、失败、奖励回调证据。
- **影响文件**：
  - `Assets/Plugins/Android/mainTemplate.gradle`
  - `ProjectSettings/AndroidResolverDependencies.xml`
  - 只读参考：`Packages/com.guru.artifact.fusionads/Editor/Dependencies.xml`
  - 受影响链路：`RewardAdHelper`、`InterstitialAdHelper`、`GameSDKService`、Dig 奖励发放入口及其它广告消费者。
- **Git 依据**：工作区 diff 将 `guru.ads.fusion:fusionads` 从 1.5.1 改为 1.5.2；Resolver package 同步为 1.5.2，并登记 1.5.2 本地 Maven 产物。最近三天没有业务提交可以提供已合入后的 CI/发布验证证据。
- **扩散链路**：Gradle 模板 → External Dependency Resolver/本地 Maven → Android 构建与裁剪 → FusionAds SDK 初始化 → 广告加载/展示 → 成功、失败、关闭与奖励回调 → 奖励到账、插屏策略、收入与用户进程恢复。
- **建议**：发布前执行一次删除旧 Gradle 缓存影响的 Android 清洁导出或 AAB/IL2CPP 构建；检查最终依赖树只有 1.5.2；在 Android 真机覆盖初始化、无填充、加载失败、展示成功、用户关闭、奖励成功、回调只触发一次以及原生覆盖返回后输入恢复。若异常位于只读 GuruSDK，停止在游戏仓库内修改，交由 GuruSDK 维护方处理。
