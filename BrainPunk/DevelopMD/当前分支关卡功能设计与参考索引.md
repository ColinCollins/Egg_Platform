## 4. 代码与资源参考

### 共享主流程

- `Assets/Game/Scripts/Play/PlayCtrl.cs`：`CreateLevelAsync` 使用 `Assets/Game/Prefabs/Level/{path}.prefab` 加载关卡；是否进入正常主线取决于 LevelData/LevelSort，而不是 Prefab 是否存在。
- `Assets/Game/Scripts/Level/BaseLevelCtrl.cs`：五关都继续复用标准控制、门触发、失败重开和成功结算链。
- `Assets/Game/Scripts/Level/MainLevel/Level_46/Level46冲撞撞飞实现记录.md`：Level 83/104 的撞飞表现参考；只是实现参考，不是这些关卡的需求来源。

### 关卡隔离

- 五关的纯规则分别位于 `Level_078/083/103/104/105/Domain/`，对应 `Game.LevelXXX.Domain.asmdef` 均保持零 Unity 引用。
- Level 78 使用本关 `Level78ActorCtrl`；Level 83 使用 `Assets/Game/Scripts/Level/Actor/Level83ActorCtrl.cs` 和 `Level83RivalActorCtrl.cs`。单关动画没有并入共享 `ActorCtrl`。
- Level 103、104、105 使用“根 `BaseLevelCtrl` + 本关组合编排组件”结构，不替换共享主流程。

### Level 105 假 UI

- 资源位于 `Assets/Game/Prefabs/Level/Level_105/Resources/`：
  - `Level105_CommonGetRewardPopup.prefab`
  - `Level105_GameVictoryPanel.prefab`
  - `Level105_GameVictoryPanel_Reward.prefab`
- 本关视图读取 PassedLevels、分享状态、分享奖励配置、NoAds 状态和关卡星星用于展示；当前本关脚本中未发现直接发奖、保存、广告、分享、下一关或 analytics 调用。
- “未发现直接调用”不等于运行时已证明无副作用。Variant 继承的业务组件和 `CustomButton.IsBlockClick` 必须通过 PlayMode 验证。
